Install HiPaCs

Use one Conda environment for compilers and numerical libraries, then build the required Trilinos packages into that environment.

Quick start

One command creates the supported environment.

The installer creates or updates the hipacs environment, builds Trilinos 17.0.0, checks the Makefile configuration, and compiles FEM with UMFPACK, PETSc, OpenMP, MPI, and HDF5. Pardiso remains optional. It does not run a simulation.

1 · Clone
git clone https://github.com/YongbinChoi91/HiPaCs.git
cd HiPaCs
2 · Install
bash install.sh
3 · Activate
conda activate hipacs

environment.yml ↗ INSTALL.md ↗ install_trilinos.sh ↗

Platform preparation

Install Miniforge, then use the same repository workflow.

Prerequisites

  • Apple Silicon Mac
  • Xcode Command Line Tools
  • Miniforge arm64
  • Git
xcode-select --install
# Install Miniforge arm64, then restart the shell
conda --version
bash install.sh

The Makefiles prefer the Conda OpenMP runtime and fall back to Homebrew libomp only when necessary. Do not mix both runtimes in one executable.

Prerequisites

  • Ubuntu 24.04 LTS recommended
  • Ubuntu 22.04 LTS compatible
  • Miniforge x86_64 or arm64
  • Git and basic system certificates
sudo apt update
sudo apt install -y git curl ca-certificates
# Install Miniforge, then restart the shell
conda --version
bash install.sh

Linux builds use -fopenmp. Other distributions require manual compiler and runtime configuration.

Dependency model

Conda supplies the toolchain; Trilinos is built from source.

Conda

Compiler and numerical stack

C/C++/Fortran compilers, OpenMPI, SuiteSparse, PETSc, HDF5, BLAS/LAPACK, OpenMP, CMake, Ninja, and pkg-config.

Python

Postprocessing stack

Python, NumPy, Matplotlib, h5py, and a Qt backend for interactive plotting.

Source build

Trilinos 17.0.0

Sacado, Teuchos, and Kokkos with MPI and OpenMP, installed under $CONDA_PREFIX/hipacs-trilinos.

# Rebuild Trilinos explicitly
conda activate hipacs
bash scripts/install_trilinos.sh

# Select another tested tag or commit
TRILINOS_REF=<tag-or-commit> bash scripts/install_trilinos.sh

Build profile

Supported backends are enabled by default.

Default

UMFPACK + PETSc + OpenMP + MPI + HDF5

The standard Makefile defaults enable the complete supported configuration.

make -C FEM clean
make -C FEM
Optional

MKL Pardiso

Enable Pardiso only after providing compatible MKL libraries for the current platform.

make -C FEM \
  USE_PARDISO=1 \
  MKL_LIBS="<MKL link flags>"

Build targets

Three Makefiles build the application entry points.

FEM/Makefile

General FEM / VEM / FSI

make -C FEM
make -C FEM run

Produces FEM/bin/fem.

Multiscale/Makefile

Macro/RVE analysis

make -C Multiscale
make -C Multiscale run

Produces Multiscale/bin/multiscale.

RVEtest/Makefile

Standalone periodic RVE

make -C RVEtest
make -C RVEtest run

Produces RVEtest/bin/single_rve.

Select a weak form at build time

make -C FEM \
  MODEL_SRC=models/Elastic_Models/weak_form_hyper_elastic.cpp

Changing MODEL_SRC updates the model stamp and rebuilds the required objects.

Postprocessing

Use interactive plotting on desktops and a file backend on headless hosts.

Desktop

Interactive Matplotlib window

conda activate hipacs
python scripts/plot_vtk_result.py \
  <result.vtk> \
  --post <Postprocessing.txt>

Requires NumPy, Matplotlib, and a GUI backend. These are included in environment.yml.

Headless Ubuntu

Non-interactive rendering

export MPLBACKEND=Agg
python scripts/plot_multiscale_dashboard.py \
  <macro.vtk> \
  --no-show \
  --save output/dashboard.png

Use this mode over SSH, in containers, or on compute nodes without a display server.

Diagnostics

Inspect resolved paths before changing compiler flags.

make -C FEM print-config
make -C FEM check-trilinos
make -C FEM check-petsc
make -C FEM check-openmp

Conda is not active

The Makefiles stop when CONDA_PREFIX is empty. Run conda activate hipacs.

Sacado is missing

Confirm SACADO_DIR=$CONDA_PREFIX/hipacs-trilinos and rerun the Trilinos installer.

PETSc is not found

Run pkg-config --cflags --libs PETSc or override PETSC_CFLAGS and PETSC_LIBS.

Optional Pardiso

Set USE_PARDISO=1 only after providing compatible platform-specific MKL_LIBS.
