Iterative solver and Schur approximation

Mechanical-pressure systems use PETSc FieldSplit. The exact pressure Schur complement is expensive, so the backend selects an approximation.

S = Kpp − KpmKmm−1Kmp
  • Factorization: lower, upper, or full block coupling.
  • Matrix-based: A11, SELFP, or FULL.
  • Pressure operators: mass, Laplacian, or a weighted combination.
  • PCD: an operator chain using Mp, Kp, and Ap.
