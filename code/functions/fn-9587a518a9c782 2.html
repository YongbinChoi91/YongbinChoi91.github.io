problem_has_fluid_like_domain()

============================================================================ Unified time-stepping layer. Every problem is solved as a Problem. Single-domain runs are represented by the mesh reader/main as one domain, not by a separate solver. The solver assembles every compiled continuum domain into one global CSR system using shared DOFs or each domain's dof_offset. Unsupported domain types are intentionally rejected by the reader until their constitutive element interfaces are added. ============================================================================

static bool problem_has_fluid_like_domain(const Problem& problem){
    for(const Domain& domain: problem.domains){
        const std::string name = lower_copy(domain.name);
        if(name.find("fluid") != std::string::npos) return true;
        const std::vector<std::string> active = active_constitutive_field_names(domain.mesh);
        if(contains_active_field(active, "velocity") || contains_active_field(active, "pressure")) return true;
    }
    return false;
}
