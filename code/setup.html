Setup

Application and input setup

Application drivers select the solve path and load the mesh, boundary, field, material, solver, and output configuration.

Application entry points

Top-level drivers

These files coordinate input, solve, and output. Implementation details remain in the core modules.

apps/main.cpp

General simulation driver

Runs the standard FEM, solid, fluid, FSI, dynamic, and VEM workflows.

apps/multiscale_main.cpp

Multiscale driver

Coordinates the macro problem with microscopic RVE configuration and solves.

apps/single_rve_pbc.cpp

Single-RVE driver

Runs one periodic RVE problem for direct homogenization and diagnostics.

Runtime input

Input files and major structure

The selected application reads these files before entering the core solve path.

ProblemMesh.txt

Mesh and domain topology

Defines spatial dimension, mesh type, active fields, nodes, boundary groups, domains, element types, and element connectivity.

  • DIM
  • MESH_TYPE
  • FIELDS
  • *_NODES
  • MIXED_BOUNDARY_*
  • DOMAIN / TYPE
  • MIXED_ELEMENTS
BC.txt

Boundary conditions

Assigns prescribed values and loads to named mesh boundary groups and field components.

  • DIRICHLET
  • NEUMANN
  • boundary selector
  • field component
  • value expression
DOFS_info.txt

Field and local-state layout

Controls active field ordering, domain participation, history variables, and optional VEM interpolation order.

  • field_key
  • domain
  • history
  • vem_order
Material.txt

Physical and material parameters

Provides fluid, structure, constitutive, and mesh-motion constants used by the selected weak form.

  • rho / mu
  • youngs_modulus
  • poisson_ratio
  • structure_rho
  • mesh_motion_*
Solver.txt

Time and nonlinear/linear solve controls

Configures quadrature, time stepping, Newton convergence, backend selection, KSP/PC, Schur options, and diagnostics.

  • GAUSS_ORDER
  • dt / total_time
  • max_iter / tol
  • solver_backend
  • linear_solver
  • preconditioner
  • fieldsplit_* / schur_*
Postprocessing.txt

Output and derived results

Controls output locations and VTK, HDF5, CSV, force, minimum-Jacobian, sampling, and plot generation.

  • output_root
  • vtk_output
  • hdf5_output
  • force_output
  • minJ_output
  • hysteresis_output
