Framework extensibility

Built for research extensions.

The framework is intended to support experiments where fields, weak forms, element technology, material histories, and coupled-domain workflows evolve over time.

Fields

Flexible field registry

Velocity, displacement, pressure, temperature, or future fields can be described through the field/DOF layer instead of hard-coding a single application layout.

History

Local internal variables

Plasticity, viscoelasticity, multiscale RVE states, and other local variables can be stored at Gauss points without becoming global DOFs.

Methods

FEM, VEM, multiphysics, multiscale

The same global infrastructure is prepared for classical FEM elements, polygonal VEM elements, domain coupling, and macro-micro workflows.

Extension rule

Prefer adding a new local model, field declaration, or postprocessing diagnostic over creating a separate solver path. This keeps the framework coherent as the project grows.

Why this matters

Research code often changes quickly. A modular framework makes it easier to compare formulations without duplicating mesh readers, assembly routines, nonlinear solvers, or output code.
