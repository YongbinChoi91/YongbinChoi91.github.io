Framework / Multiscale layer

Multiscale / RVE

The multiscale layer connects a macro weak form to a micro RVE problem through periodic constraints, homogenized stress, sensitivity transfer, warm-start caches, and diagnostics.

Purpose

What this module does

The module configures a reusable micro problem, solves periodic RVE systems at standalone or macro Gauss-point level, returns integrated and averaged Piola stress, and optionally computes sensitivity information for macro tangent support.

Extension point

Exchange constitutive data through a macro–micro contract

A micro model receives the macro deformation state and returns a homogenized response and, when available, its consistent sensitivity. The macro assembly should not depend on the internal RVE solution method.
