Solid Mechanics / Dynamic / Newmark

Dynamic Newmark solid with Gauss-point velocity and acceleration history

This page uses the same Theory / Simulation platform as the nonlinear elastic and inelastic examples. The global finite element unknown is still the displacement field, while velocity and acceleration are reconstructed and stored locally at Gauss points through the Newmark update.

Theory

Newmark discretization inside a displacement-only nonlinear solid.

The dynamic problem should not be documented as if velocity and acceleration were extra global DOFs. In this implementation, the global vector contains only displacement. Velocity and acceleration are Gauss-point history values used to reconstruct the inertial residual during each Newton trial.

1 · Global unknown

Displacement remains the only assembled field

\[ \mathbf{x}_{n+1} \equiv \mathbf{u}_{n+1} \]

The assembly asks the weak form for only the displacement field. This keeps the global CSR system identical in structure to static hyperelasticity: the additional dynamic quantities are not numbered as nodal unknowns.

2 · Local history

Velocity and acceleration live at Gauss points

\[ \mathbf{h}_{n}^{gp} = \begin{bmatrix} \mathbf{v}_{n}^{gp} \\ \mathbf{a}_{n}^{gp} \end{bmatrix} \]

In 2D, history newmark 4 means \([v_x^{gp}, v_y^{gp}, a_x^{gp}, a_y^{gp}]\) at every integration point. These values are local material-point states, not global field values.

3 · Newmark acceleration

Acceleration is reconstructed from the current displacement iterate

\[ \mathbf{a}_{n+1}^{gp} = \frac{1}{\beta \Delta t^2} \left(\mathbf{u}_{n+1}^{gp}-\mathbf{u}_{n}^{gp}-\Delta t\,\mathbf{v}_{n}^{gp}\right) - \left(\frac{1}{2\beta}-1\right)\mathbf{a}_{n}^{gp} \]

Because \(\mathbf{u}_{n+1}^{gp}\) comes from the current Newton iterate, the inertial term contributes directly to the residual and to the AD tangent.

4 · Newmark velocity

Velocity is a candidate history value

\[ \mathbf{v}_{n+1}^{gp} = \mathbf{v}_{n}^{gp} + \Delta t\left((1-\gamma)\mathbf{a}_{n}^{gp}+\gamma\mathbf{a}_{n+1}^{gp}\right) \]

The computed \(\mathbf{v}_{n+1}^{gp}\) and \(\mathbf{a}_{n+1}^{gp}\) are first written to h_trial . They are committed only when the time step is accepted.

5 · Scalar weak form

Elastic and inertial virtual work in one AD expression

\[ G(\mathbf{u}_{n+1},\delta\mathbf{u}) = \int_{\Omega_0} \mathbf{P}(\mathbf{F}(\mathbf{u}_{n+1})) : \nabla_0\delta\mathbf{u}\,dV + \int_{\Omega_0} \rho\,\mathbf{a}_{n+1}(\mathbf{u}_{n+1})\cdot\delta\mathbf{u}\,dV \]

The residual is obtained from \(\partial G/\partial\delta\mathbf{u}\), and the tangent is obtained by differentiating that residual with respect to \(\mathbf{u}_{n+1}\). Therefore the mass/inertia contribution is consistent with the Newmark discretization.

6 · Commit rule

Rejected steps must not overwrite local states

\[ \mathbf{h}_{trial}^{gp} = \begin{bmatrix} \mathbf{v}_{n+1}^{gp} \\ \mathbf{a}_{n+1}^{gp} \end{bmatrix}, \qquad \mathbf{h}_{n+1}^{gp} \leftarrow \mathbf{h}_{trial}^{gp} \quad\text{only after convergence.} \]

This is the same history-management logic used by plasticity and viscoelasticity: local trial states are allowed during Newton iterations, but the previous accepted history remains intact if adaptive stepping rejects the trial.

Simulation

Input files and implementation flow for the Newmark example.

The simulation setup exposes the dynamic model through the same input-file style as the other solid examples: field declaration, local history declaration, material/time-integration parameters, boundary loading, solver controls, and output settings.

DOFS_info.txt

Separate global DOFs from local history variables. 

field_key displacement
history newmark 4

The first line creates the global displacement unknowns. The second line creates four local values per Gauss point in 2D: two velocity components and two acceleration components.

Material.txt

Elastic constants plus Newmark parameters. 

youngs_modulus 200
poisson_ratio 0.3

newmark_beta 0.25
newmark_gamma 0.5

The average-acceleration choice \(\beta=0.25\), \(\gamma=0.5\) is a common baseline for implicit structural dynamics. Density is read through the solid material parameter path when specified.

BC.txt

Time-dependent traction loading. 

DIRICHLET LEFT 0 0.0
DIRICHLET LEFT 1 0.0
NEUMANN RIGHT 1 sin(pi*t)/(1.0+exp(80.0*(t-2.0)))

The left side is fixed in both displacement components. The right boundary receives a transient vertical traction that is smoothly damped after the loading interval.

Solver.txt

Transient solve with adaptive time stepping. 

dt 0.1
total_time 12.0
adaptive_dt on
dt_max 0.02
max_iter 20
tol 1e-8
history_diagnostics on

The global Newton solve advances displacement. During each accepted step, the local Newmark history is advanced consistently with the converged displacement state.

1. The active model assembles only displacement DOFs. 
std::vector<std::string> active_constitutive_field_names(const FieldMesh& mesh) {
    (void)mesh;
    return {"displacement"};
}

This is the key difference from a mixed displacement-velocity formulation. Newmark velocity and acceleration do not enlarge the global linear system.

2. The weak form requires Gauss-point Newmark history. 
if (!state.material_history) {
    throw std::runtime_error(
        "Add 'history newmark 2*dim' to DOFS_info.txt"
    );
}

The local history object is attached to the element/Gauss-point state by the generic history store. Its size is checked as 2*dim .

3. Previous accepted displacement is read from the assembler state. 
u_gp   = interpolate(u_{n+1}, N)
u_n_gp = interpolate(u_n, N)

The current displacement is the Newton variable, while the previous accepted displacement is supplied through state.x_n_elem . This makes the update local but still consistent with the global step.

4. Candidate history is written during weak-form evaluation. 
hist.h_trial[i]       = v_{n+1,i}^{gp};
hist.h_trial[dim + i] = a_{n+1,i}^{gp};

This candidate state is useful for output and diagnostics, but it becomes the new accepted history only after the solver accepts the time step.

5. The inertial term is part of the same scalar AD weak form. 
G += rho * a_newmark_gp[i] * delta_u_gp[i] * dV;

Since a_newmark_gp depends on the current displacement iterate, the AD tangent automatically contains the dynamic mass contribution for the Newmark step.

Strong form
\[\rho\,\ddot{\mathbf u}-\operatorname{Div}\mathbf P(\mathbf F)=\mathbf0\quad\text{in }\Omega_0.\]
Boundary conditions
\[\mathbf u=\bar{\mathbf u}\text{ on }\Gamma_D,\qquad \mathbf P\mathbf N=\bar{\mathbf t}(t)\text{ on }\Gamma_N.\]

The actual support and transient traction are defined in input/BC.txt.

Weak form
\[G_e=\int_{\Omega_0^e}\rho\mathbf a_{n+1}\cdot\delta\mathbf u+\mathbf P:\nabla_0\delta\mathbf u\,dV.\]

cp -R FEM/input FEM/input.bak
cp Web/examples/newmark/weak_form.cpp FEM/models/weak_form.cpp
cp Web/examples/newmark/input/*.txt FEM/input/
make -C FEM MODEL_SRC=models/weak_form.cpp run
