Solid Mechanics / Dynamic / Newmark

Dynamic Newmark solid with Gauss-point velocity and acceleration history

This page uses the same Theory / Simulation platform as the nonlinear elastic and inelastic examples. The global finite element unknown is still the displacement field, while velocity and acceleration are reconstructed and stored locally at Gauss points through the Newmark update.

Theory

Newmark discretization inside a displacement-only nonlinear solid.

The dynamic problem should not be documented as if velocity and acceleration were extra global DOFs. In this implementation, the global vector contains only displacement. Velocity and acceleration are Gauss-point history values used to reconstruct the inertial residual during each Newton trial.

1 · Global unknown

Displacement remains the only assembled field

\[ \mathbf{x}_{n+1} \equiv \mathbf{u}_{n+1} \]

The assembly asks the weak form for only the displacement field. This keeps the global CSR system identical in structure to static hyperelasticity: the additional dynamic quantities are not numbered as nodal unknowns.

2 · Local history

Velocity and acceleration live at Gauss points

\[ \mathbf{h}_{n}^{gp} = \begin{bmatrix} \mathbf{v}_{n}^{gp} \\ \mathbf{a}_{n}^{gp} \end{bmatrix} \]

In 2D, history newmark 4 means \([v_x^{gp}, v_y^{gp}, a_x^{gp}, a_y^{gp}]\) at every integration point. These values are local material-point states, not global field values.

3 · Newmark acceleration

Acceleration is reconstructed from the current displacement iterate

\[ \mathbf{a}_{n+1}^{gp} = \frac{1}{\beta \Delta t^2} \left(\mathbf{u}_{n+1}^{gp}-\mathbf{u}_{n}^{gp}-\Delta t\,\mathbf{v}_{n}^{gp}\right) - \left(\frac{1}{2\beta}-1\right)\mathbf{a}_{n}^{gp} \]

Because \(\mathbf{u}_{n+1}^{gp}\) comes from the current Newton iterate, the inertial term contributes directly to the residual and to the AD tangent.

4 · Newmark velocity

Velocity is a candidate history value

\[ \mathbf{v}_{n+1}^{gp} = \mathbf{v}_{n}^{gp} + \Delta t\left((1-\gamma)\mathbf{a}_{n}^{gp}+\gamma\mathbf{a}_{n+1}^{gp}\right) \]

The computed \(\mathbf{v}_{n+1}^{gp}\) and \(\mathbf{a}_{n+1}^{gp}\) are first written to h_trial . They are committed only when the time step is accepted.

5 · Scalar weak form

Elastic and inertial virtual work in one AD expression

\[ G(\mathbf{u}_{n+1},\delta\mathbf{u}) = \int_{\Omega_0} \mathbf{P}(\mathbf{F}(\mathbf{u}_{n+1})) : \nabla_0\delta\mathbf{u}\,dV + \int_{\Omega_0} \rho\,\mathbf{a}_{n+1}(\mathbf{u}_{n+1})\cdot\delta\mathbf{u}\,dV \]

The residual is obtained from \(\partial G/\partial\delta\mathbf{u}\), and the tangent is obtained by differentiating that residual with respect to \(\mathbf{u}_{n+1}\). Therefore the mass/inertia contribution is consistent with the Newmark discretization.

6 · Commit rule

Rejected steps must not overwrite local states

\[ \mathbf{h}_{trial}^{gp} = \begin{bmatrix} \mathbf{v}_{n+1}^{gp} \\ \mathbf{a}_{n+1}^{gp} \end{bmatrix}, \qquad \mathbf{h}_{n+1}^{gp} \leftarrow \mathbf{h}_{trial}^{gp} \quad\text{only after convergence.} \]

This is the same history-management logic used by plasticity and viscoelasticity: local trial states are allowed during Newton iterations, but the previous accepted history remains intact if adaptive stepping rejects the trial.

Simulation

Input files and implementation flow for the Newmark example.

The simulation setup exposes the dynamic model through the same input-file style as the other solid examples: field declaration, local history declaration, material/time-integration parameters, boundary loading, solver controls, and output settings.

DOFS_info.txt

Separate global DOFs from local history variables. 

field_key displacement
history newmark 4

The first line creates the global displacement unknowns. The second line creates four local values per Gauss point in 2D: two velocity components and two acceleration components.

Material.txt

Elastic constants plus Newmark parameters. 

youngs_modulus 200
poisson_ratio 0.3

newmark_beta 0.25
newmark_gamma 0.5

The average-acceleration choice \(\beta=0.25\), \(\gamma=0.5\) is a common baseline for implicit structural dynamics. Density is read through the solid material parameter path when specified.

BC.txt

Time-dependent traction loading. 

DIRICHLET LEFT 0 0.0
DIRICHLET LEFT 1 0.0
NEUMANN RIGHT 1 sin(pi*t)/(1.0+exp(80.0*(t-2.0)))

The left side is fixed in both displacement components. The right boundary receives a transient vertical traction that is smoothly damped after the loading interval.

Solver.txt

Transient solve with adaptive time stepping. 

dt 0.1
total_time 12.0
adaptive_dt on
dt_max 0.02
max_iter 20
tol 1e-8
history_diagnostics on

The global Newton solve advances displacement. During each accepted step, the local Newmark history is advanced consistently with the converged displacement state.

2. make_newmark_parameters
static NewmarkParameters make_newmark_parameters(const ProblemParameters& params) {
    NewmarkParameters nm;
    nm.newmark_beta = params.material.newmark_beta;
    nm.newmark_gamma = params.material.newmark_gamma;
    return nm;
}
3. weak_scalar_hyperelastic_newmark_solid
static Scalar weak_scalar_hyperelastic_newmark_solid(
    const FieldMesh& mesh,
    int elem_id,
    const std::vector<Scalar>& x_elem,     // current Newton iterate u_{n+1}
    const std::vector<Scalar>& test_elem,  // independent virtual displacement delta_u
    const ProblemParameters& params,
    const ElementState& state
) {
    const NewmarkLocalLayout L = make_newmark_layout(mesh, elem_id);
    const auto& U = L.field("displacement");

    if (static_cast<int>(x_elem.size()) != L.n_local()) {
        throw std::runtime_error("Bad current element vector size in Newmark hyper-elastic weak form.");
    }
    if (state.past_dofs.size() < 1 || static_cast<int>(state.past_dofs[0].size()) != L.n_local()) {
        throw std::runtime_error("Bad previous element vector size in Newmark hyper-elastic weak form.");
    }
    if (test_elem.size() != x_elem.size()) {
        throw std::runtime_error("Bad test element vector size in Newmark hyper-elastic weak form.");
    }

    require_newmark_history(state, L.dim);

    const double dt = state.dt;
    if (dt <= 0.0) {
        throw std::runtime_error("Newmark hyper-elastic weak form requires positive dt.");
    }

    const double rho = params.material.structure_rho; // solid density
    const double E   = params.material.youngs_modulus;
    const double nu  = params.material.poisson_ratio;

    const NewmarkParameters nm = make_newmark_parameters(params);
    if (nm.newmark_beta <= 0.0) {
        throw std::runtime_error("Newmark beta must be positive.");
    }

    Scalar G(0.0);

    // Geometry is displacement-based because this is a displacement-only solid.
    const ElementGeometry geom = make_displacement_element_geometry(mesh, elem_id);

    const auto gps = gauss_rule(U.element_type, params.solver.gauss_order);
    if (state.material_history->gp.size() != gps.size()) {
        // This should already be initialized by initialize_material_history_store.
        // Resize here only as a defensive fallback.
        state.material_history->gp.resize(gps.size());
    }

    for (int q = 0; q < static_cast<int>(gps.size()); ++q) {
        const auto& gp = gps[q];

        MaterialPointHistory& hist = state.material_history->gp[q];

        // ---------------------------------------------------------------------
        // History layout at this Gauss point:
        //   h_n[0..dim-1]       : v_n^gp
        //   h_n[dim..2dim-1]    : a_n^gp
        //   h_trial receives v_{n+1}^gp and a_{n+1}^gp during Newton evaluation.
        // ---------------------------------------------------------------------
        const int required_history = 2 * L.dim;
        if (static_cast<int>(hist.h_n.size()) != required_history) {
            throw std::runtime_error(
                "Bad Newmark history size. Use 'history newmark 2*dim' in DOFS_info.txt "
                "(2D -> 4, 3D -> 6)."
            );
        }
        if (static_cast<int>(hist.h_trial.size()) != required_history) {
            hist.h_trial.assign(required_history, 0.0);
        }

        const ShapeData su = compute_shape(U.element_type, gp.xi, gp.eta, gp.zeta);
        const JacobianData Jgeo = compute_jacobian_data(geom, su);
        if (Jgeo.detJ <= 0.0) {
            throw std::runtime_error("Negative reference detJ in Newmark hyper-elastic solid element.");
        }

        const auto dNu = compute_dN_dx(su, Jgeo);
        const double dV = Jgeo.detJ * gp.weight;

        // ---------------------------------------------------------------------
        // Current and previous accepted displacement at the Gauss point.
        //
        // u_gp   = sum_a N_a u_{a,n+1}
        // u_n_gp = sum_a N_a u_{a,n}
        //
        // state.past_dofs[0] is filled by the assembler from the previous accepted
        // global solution x_n in the same local field order as x_elem.
        // ---------------------------------------------------------------------
        const auto u_gp =
            hpx::field_value_as<Scalar>(L, "displacement", x_elem, su.N);

        const auto u_n_gp =
            hpx::field_value_as<Scalar>(L, "displacement", state.past_dofs[0], su.N);

        // Virtual displacement and virtual deformation gradient.
        const auto delta_u_gp =
            hpx::field_value_as<Scalar>(L, "displacement", test_elem, su.N);

        const auto deltaF =
            hpx::field_grad_as<Scalar>(L, "displacement", test_elem, dNu);

        // ---------------------------------------------------------------------
        // Elastic part:
        //   F = I + Grad(u)
        //   P = Neo-Hookean first Piola stress
        //   G_elastic += int P : deltaF dV
        //
        // In 2D, F is embedded into 3D as plane strain before evaluating P.
        // ---------------------------------------------------------------------
        const auto F = hpx::deformation_gradient_as<Scalar>(L, x_elem, dNu);
        const auto F3 = hpx::embed_plane_strain_3d(F, L.dim);
        const auto P3 = hpx::neo_hookean_first_piola_young(F3, E, nu);

        for (int i = 0; i < L.dim; ++i) {
            for (int A = 0; A < L.dim; ++A) {
                G += P3[i][A] * deltaF[i][A] * Scalar(dV);
            }
        }

        // ---------------------------------------------------------------------
        // Newmark inertia part:
        //
        // h_n stores the previous Gauss-point velocity/acceleration:
        //   v_n^gp = h_n[0..dim-1]
        //   a_n^gp = h_n[dim..2dim-1]
        //
        // Current acceleration is reconstructed locally from current u:
        //   a_{n+1}^gp =
        //       (u_{n+1}^gp - u_n^gp - dt v_n^gp)/(beta dt^2)
        //       - (1/(2 beta) - 1) a_n^gp
        //
        // Then we add:
        //   G_inertia += int rho a_{n+1}^gp . delta_u^gp dV
        //
        // Because a_{n+1} is written with Scalar, AD automatically contributes
        // the consistent mass-like tangent term:
        //   d(rho a_{n+1})/du = rho/(beta dt^2) * N_a N_b.
        // ---------------------------------------------------------------------
        std::vector<Scalar> a_np1_gp(L.dim, Scalar(0.0));
        std::vector<Scalar> v_np1_gp(L.dim, Scalar(0.0));

        const double inv_beta_dt2 = 1.0 / (nm.newmark_beta * dt * dt);
        const double accel_old_factor = (1.0 / (2.0 * nm.newmark_beta)) - 1.0;

        for (int i = 0; i < L.dim; ++i) {
            const double v_n_gp = hist.h_n[i];
            const double a_n_gp = hist.h_n[L.dim + i];

            a_np1_gp[i] =
                Scalar(inv_beta_dt2) *
                (u_gp[i] - u_n_gp[i] - Scalar(dt * v_n_gp))
                - Scalar(accel_old_factor * a_n_gp);

            v_np1_gp[i] =
                Scalar(v_n_gp)
                + Scalar(dt) *
                  (Scalar(1.0 - nm.newmark_gamma) * Scalar(a_n_gp)
                   + Scalar(nm.newmark_gamma) * a_np1_gp[i]);

            G += Scalar(rho) * a_np1_gp[i] * delta_u_gp[i] * Scalar(dV);
        }

        // ---------------------------------------------------------------------
        // Trial history update.
        //
        // This is called inside Newton iterations, so it must be treated as
        // "candidate state".  The solver's commit_material_history_store()
        // performs the actual update h_trial -> h_n only after the time step
        // is accepted.  If the time step is rejected, h_n remains unchanged.
        // ---------------------------------------------------------------------
        for (int i = 0; i < L.dim; ++i) {
            hist.h_trial[i]         = scalar_value(v_np1_gp[i]);
            hist.h_trial[L.dim + i] = scalar_value(a_np1_gp[i]);
        }
        hist.state_trial = 0.0;
    }

    return G;
}
4. compute_constitutive_element_system
ElementSystem compute_constitutive_element_system(
    const FieldMesh& mesh,
    int elem_id,
    const Vector& x_elem,
    const ProblemParameters& params,
    const ElementState& state
) {
    return hpx::scalar_weak_form_element_system(
        x_elem,
        [&](const auto& x_ad, const auto& test_ad) {
            return weak_scalar_hyperelastic_newmark_solid(mesh, elem_id, x_ad, test_ad, params, state);
        }
    );
}
Strong form
\[\rho\,\ddot{\mathbf u}-\operatorname{Div}\mathbf P(\mathbf F)=\mathbf0\quad\text{in }\Omega_0.\]
Boundary conditions
\[\mathbf u=\bar{\mathbf u}\text{ on }\Gamma_D,\qquad \mathbf P\mathbf N=\bar{\mathbf t}(t)\text{ on }\Gamma_N.\]

The actual support and transient traction are defined in input/BC.txt.

Weak form
\[G_e=\int_{\Omega_0^e}\rho\mathbf a_{n+1}\cdot\delta\mathbf u+\mathbf P:\nabla_0\delta\mathbf u\,dV.\]
