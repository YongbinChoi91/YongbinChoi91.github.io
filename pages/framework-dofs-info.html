Framework / Input format

DOFS_info.txt

This file defines the active Newton fields, their ordering, optional VEM order, and Gauss-point history-variable declarations.

Core idea

Field order is a user-level setting.

The field_key line uses physical field names such as displacement , velocity , pressure , and temperature . The order controls the global DOF layout and the element-local LocalFieldView order used by weak-form kernels.

Solid-only example

A pure displacement problem keeps the global Newton vector minimal. 

# Global unknown/element-local field order
field_key displacement

Fluid / FSI-style example

Mixed problems can expose several named fields in a controlled order. 

# Mixed mechanical-pressure layout
field_key velocity displacement pressure

# Thermo-coupled variant
# field_key velocity displacement temperature pressure

Optional declarations

  • history plasticity 5 declares five Gauss-point history variables.
  • VEM linear or VEM quadratic can select the polygon interpolation order.
  • domain solid may provide a display name for single-domain runs.

Design point

Only fields listed in field_key become global Newton unknowns. History variables are local material state variables and are not included in the global sparse matrix.
