History Variables

History variables are Gauss-point state variables used by path-dependent models such as plasticity or viscoelasticity.

Local state

History variables are not global DOFs.

They are allocated per domain, element, and Gauss point. The nonlinear solver still solves only for the active fields in field_key , while the weak form updates trial history variables locally and commits them after an accepted step.

Elasto-plastic example 

field_key displacement

# 2D plane-strain plasticity history
# {h11, h22, h33, h12, gamma}
history plasticity 5

Where it is used

  • MaterialHistoryStore stores history per domain/element/Gauss point.
  • h_n is the accepted state from the previous step.
  • h_trial is the current Newton/trial update.
  • commit_material_history_store() accepts the trial state after convergence.
