Fluid-Structure Interaction

One coupled ALE formulation for an incompressible fluid and a Neo-Hookean solid. Follow the theory, then the actual mixed finite-element implementation and its 2D input files.

Theory

From domain balances to one coupled residual.

The unknowns are velocity \(\mathbf v\), displacement \(\mathbf u\), and pressure \(p\). Displacement moves the fluid mesh in \(\Omega_f^0\) and describes the physical solid in \(\Omega_s^0\); velocity is active in both domains.

1 · ALE kinematics

Reference and current configurations

\[\mathbf x=\mathbf X+\mathbf u(\mathbf X,t),\qquad \mathbf F=\mathbf I+\nabla_0\mathbf u,\qquad J=\det\mathbf F>0,\qquad \mathbf w=\partial_t\mathbf u.\]

All integrals below use the reference domains. In the fluid, \(\mathbf w\) is the mesh velocity and \(\nabla_x\mathbf v=\nabla_0\mathbf v\,\mathbf F^{-1}\). The example uses two in-plane components; the solid constitutive law embeds \(\mathbf F\) in 3D with \(F_{33}=1\) for plane strain.

2 · Fluid strong form

Incompressible Navier–Stokes in ALE coordinates

\[\rho_f J\left[\left.\partial_t\mathbf v\right|_{\mathbf X}+\nabla_0\mathbf v\,\mathbf F^{-1}(\mathbf v-\mathbf w)\right]-\operatorname{Div}\mathbf P_f=\mathbf0,\qquad J\mathbf F^{-T}:\nabla_0\mathbf v=0.\]
\[\mathbf P_f=J\boldsymbol\sigma_f\mathbf F^{-T},\qquad \boldsymbol\sigma_f=-p\mathbf I+\eta_f\left(\nabla_0\mathbf v\,\mathbf F^{-1}+\mathbf F^{-T}(\nabla_0\mathbf v)^T\right).\]

In this implementation \(\rho_f=\texttt{rho}\) and the dynamic viscosity is \(\eta_f=\texttt{rho}\,\texttt{mu}\). Thus the input mu acts as kinematic viscosity.

3 · Solid strong form

Momentum and the velocity–displacement relation

\[\rho_s\partial_t\mathbf v-\operatorname{Div}\mathbf P_s=\mathbf0,\qquad \partial_t\mathbf u-\mathbf v=\mathbf0\quad\text{in }\Omega_s^0.\]

The solid uses the same velocity and displacement fields as the fluid-side interface. Its pressure variable is removed by a local pressure-mass equation \(\int_{\Omega_s^0}p\,\delta p\,dV=0\); it is not a solid incompressibility multiplier.

4 · Solid material

The Neo-Hookean law used by the code

\[W(\mathbf F)=\frac{\mu_s}{2}\left(\operatorname{tr}(\mathbf F^T\mathbf F)-3\right)-\mu_s\ln J+\frac{\lambda_s}{4}\left(J^2-1-2\ln J\right).\]
\[\mathbf P_s=\frac{\partial W}{\partial\mathbf F}=\mu_s(\mathbf F-\mathbf F^{-T})+\frac{\lambda_s}{2}(J^2-1)\mathbf F^{-T},\qquad \mu_s=\frac{E}{2(1+\nu)},\quad \lambda_s=\frac{E\nu}{(1+\nu)(1-2\nu)}.\]

This is the volumetric law in neo_hookean_first_piola_lame. youngs_modulus, poisson_ratio, and structure_rho supply the solid parameters.

5 · Interface conditions

Shared motion and balanced traction

\[\mathbf u_f=\mathbf u_s,\qquad \mathbf v_f=\mathbf v_s=\partial_t\mathbf u_s,\qquad \mathbf P_f\mathbf N_f+\mathbf P_s\mathbf N_s=\mathbf0\quad\text{on }\Gamma_{fs}^0.\]

Conforming interface nodes share velocity and displacement DOFs. The coupled assembly sums both domain contributions, so interface traction balance is enforced through the common weak form. Pressure connectivity is domain-specific.

6 · Boundary conditions

Conditions in the 2D input

\[v_x|_{\mathrm{INLET}}=\bar u\,\mathrm{parabolic\_profile}\,\sin\!\left(\frac{\pi\min(t,2)}4\right),\qquad v_y|_{\mathrm{INLET}}=0.\]

The solver selects an automatic fluid pressure pin at value zero. The interface is an internal shared boundary, rather than an imposed displacement history.

7 · Continuous weak form

Fluid momentum, incompressibility, and solid motion

\[G_f=\int_{\Omega_f^0}\rho_f J\left[\partial_t\mathbf v+\nabla_0\mathbf v\,\mathbf F^{-1}(\mathbf v-\mathbf w)\right]\cdot\delta\mathbf v+\mathbf P_f:\nabla_0\delta\mathbf v+\left(J\mathbf F^{-T}:\nabla_0\mathbf v\right)\delta p\,dV+G_m.\]
\[G_s=\int_{\Omega_s^0}\rho_s\partial_t\mathbf v\cdot\delta\mathbf v+\mathbf P_s:\nabla_0\delta\mathbf v+\rho_s(\partial_t\mathbf u-\mathbf v)\cdot\delta\mathbf u+p\,\delta p\,dV,\qquad G_f+G_s=0.\]

Integration by parts introduces the Piola stress terms. External natural tractions vanish for this input, while the two interface traction terms cancel for the shared velocity test field. The code uses the time-discrete form below, including its row scaling.

Mesh · HE

Hyperelastic mesh motion

\[\begin{aligned}G_m^{\mathrm{HE}}&=\int_{\Omega_f^0}c_m\mathbf P_m:\nabla_0\delta\mathbf u\,dV,\\\mathbf P_m&=\mu_m(\mathbf F-\mathbf F^{-T})\\&\quad+\frac{\lambda_m}{2}(J^2-1)\mathbf F^{-T}.\end{aligned}\]
\[\mu_m=\frac1{2(1+\nu_m)},\qquad\lambda_m=\frac{\nu_m}{(1+\nu_m)(1-2\nu_m)}.\]

mesh_motion_type HE

Mesh · BH

Weighted Laplace mesh motion

\[G_m^{\mathrm{BH}}=\int_{\Omega_f^0}\frac{c_m}{J}\nabla_0\mathbf u:\nabla_0\delta\mathbf u\,dV.\]

mesh_motion_type BH

8 · Time discretization

Shifted Crank–Nicolson weights

\[\alpha=\texttt{theta}+\Delta t,\qquad z_\alpha=\alpha z^{n+1}+(1-\alpha)z^n,\qquad\Delta z=z^{n+1}-z^n.\]

Shift_Crank_Nicolson gives \(\alpha=0.51\) at the initial \(\Delta t=0.01\), theta = 0.5. Adaptive stepping updates this weight with the actual step size. The implementation interpolates \(\mathbf F_\alpha\) and \(J_\alpha\) separately and uses \(p^{n+1}\) in the fluid stress.

\[\begin{aligned}\mathbf P_{f,\alpha}&=J_\alpha\left[-p^{n+1}\mathbf I+\eta_f\left(\nabla_0\mathbf v_\alpha\mathbf F_\alpha^{-1}+\mathbf F_\alpha^{-T}(\nabla_0\mathbf v_\alpha)^T\right)\right]\mathbf F_\alpha^{-T},\\\mathbf P_{s,\alpha}&=\alpha\mathbf P_s(\mathbf F^{n+1})+(1-\alpha)\mathbf P_s(\mathbf F^n).\end{aligned}\]
9 · Implemented time-discrete weak form

Exactly the terms assembled in each domain

\[\begin{aligned}G_f^\Delta={}&\int_{\Omega_f^0}\Big[\rho_f\frac{J^{n+1}+J^n}{2}\Delta\mathbf v+\Delta t\,\rho_f J_\alpha\nabla_0\mathbf v_\alpha\mathbf F_\alpha^{-1}\mathbf v_\alpha\\&\hspace{3em}-\rho_f J^{n+1}\nabla_0\mathbf v^{n+1}(\mathbf F^{n+1})^{-1}\Delta\mathbf u\Big]\cdot\delta\mathbf v\,dV\\&+\int_{\Omega_f^0}\Delta t\,\mathbf P_{f,\alpha}:\nabla_0\delta\mathbf v+\left(J_\alpha\mathbf F_\alpha^{-T}:\nabla_0\mathbf v^{n+1}\right)\delta p\,dV+G_m^{n+1}.\end{aligned}\]
\[\begin{aligned}G_s^\Delta=\int_{\Omega_s^0}&\rho_s\Delta\mathbf v\cdot\delta\mathbf v+\Delta t\,\mathbf P_{s,\alpha}:\nabla_0\delta\mathbf v\\&+\rho_s(\Delta\mathbf u-\Delta t\,\mathbf v_\alpha)\cdot\delta\mathbf u+p^{n+1}\delta p\,dV.\end{aligned}\]

Momentum and solid kinematics carry the step factor shown here. Fluid incompressibility uses the current velocity gradient, and the mesh equation uses current displacement. These choices reproduce weak_scalar_fluid_domain and weak_scalar_solid_domain.

10 · FEM / Newton / AD

Differentiate the scalar weak form

\[\mathbf x_e=(\mathbf v_e,\mathbf u_e,p_e),\qquad R_{e,a}=\frac{\partial G_e}{\partial\delta x_{e,a}},\qquad K_{e,ab}=\frac{\partial R_{e,a}}{\partial x_{e,b}},\qquad\mathbf K\Delta\mathbf x=-\mathbf R.\]

The 2D mesh uses Q9 velocity, Q9 displacement, and Q4 pressure interpolation. Nested Sacado AD differentiates the domain scalar, and the shared assembly scatters its residual and tangent into one global Newton system.

Code

One FEM model, two domains, one solve.

The implementation excerpts and mesh below come from FEM/models/FSI_Models/weak_form_fsi.cpp and its 2D input. HE and BH select the mesh term within this same model.

1

Read the fields and domains

Info_FSI.txt declares velocity displacement pressure. fsi_2d.txt supplies fluid and solid domains and shared interface nodes.

2

Evaluate the domain scalar

weak_scalar_domain dispatches to the fluid or solid kernel. The fluid kernel also adds the selected mesh equation.

3

Differentiate and assemble

scalar_weak_form_element_system extracts the residual and tangent. Global assembly and Newton iterations solve all active fields together.

4. Domain dispatcher

FEM/models/FSI_Models/weak_form_fsi.cpp:417

static Scalar weak_scalar_domain(
    const FieldMesh& mesh,
    int elem_id,
    const std::vector<Scalar>& x_elem,
    const std::vector<Scalar>& test_elem,
    const ProblemParameters& params,
    const ElementState& state
) {
    if (state.domain_name == "fluid") {
        return weak_scalar_fluid_domain(mesh, elem_id, x_elem, test_elem, params, state);
    }
    if (state.domain_name == "solid") {
        return weak_scalar_solid_domain(mesh, elem_id, x_elem, test_elem, params, state);
    }

    switch (state.domain_type) {
        case DomainType::Fluid:
            return weak_scalar_fluid_domain(mesh, elem_id, x_elem, test_elem, params, state);
        case DomainType::Solid:
            return weak_scalar_solid_domain(mesh, elem_id, x_elem, test_elem, params, state);
        default:
            throw std::runtime_error("Unsupported domain type in weak form.");
    }
}

6. Neo-Hookean Piola helper

core/space/kinematics.h:605

inline std::vector<std::vector<Scalar>> neo_hookean_first_piola_lame(
    const std::vector<std::vector<Scalar>>& F3,
    double lambda,
    double mu
) {
    if (static_cast<int>(F3.size()) != 3 || static_cast<int>(F3[0].size()) != 3) {
        throw std::runtime_error("Neo-Hookean first Piola helper expects a 3x3 deformation gradient.");
    }

    const Scalar J = det(F3);
    const auto FinvT = inv_transpose(F3);
    const Scalar coeff = Scalar(0.5 * lambda) * (J * J - Scalar(1.0));

    std::vector<std::vector<Scalar>> P(3, std::vector<Scalar>(3, Scalar(0.0)));
    for (int i = 0; i < 3; ++i) {
        for (int A = 0; A < 3; ++A) {
            P[i][A] = Scalar(mu) * (F3[i][A] - FinvT[i][A]) + coeff * FinvT[i][A];
        }
    }
    return P;
}

inline TimeSchemeStencils Shift_Crank_Nicolson(double theta, double dt) {
    const double shifted_theta = theta + dt;
    return {
        "Shift_Crank_Nicolson",
        {"Shift_Crank_Nicolson_Derivative", 2, {1.0, -1.0}},
        {"Shift_Crank_Nicolson_Value", 2, {shifted_theta, 1.0 - shifted_theta}}
    };
}

Run the 2D example

Use the FEM FSI runner.

After the environment setup in Installation, run from the repository root. The runner copies the selected case into FEM/input/, builds the model, and starts the solve.

cd FEM
bash run.sh fsi

The default is HE mesh motion. To use the BH mesh equation with the same 2D model, run bash run.sh fsi_bh from FEM/.
