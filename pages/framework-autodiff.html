Code Structure / Local AD helper

HPX AutoDiff

Fixed-capacity tensor-index automatic differentiation helpers for local scalar, vector, and tensor derivative checks.

Purpose

Local tensor-index AD helper

HPX AutoDiff provides small fixed-capacity active scalar, vector, and tensor types. It is used to write compact local scalar potentials and extract first or second derivatives with respect to active variables.

This module is separate from global weak-form assembly. The solver still receives local residuals and tangents through ElementSystem and assembles them into the global CSR system.

Main files

  • hpx_autodiff.h types, operators, tensor algebra, derivative extraction
  • hpx_autodiff.cpp scalar, tensor, determinant, and Neo-Hookean self-check routines
  • kinematics.h connection only; ordinary FE kinematics remain there

Key structures

  • hpx::ADScalar<MaxVars>
  • hpx::ADVector<Dim, MaxVars>
  • hpx::ADTensor2<Rows, Cols, MaxVars>
  • hpx::Tensor4<A, B, C, D>
  • hpx::Wrt<T> optional wrapper for the implemented wrt() call style

Data flow

Reset active-variable offsets Create active scalar/vector/tensor Evaluate scalar potential Extract gradient or Hessian Compare with constitutive implementation

Design point

  • Local AD helper for compact tensor-index derivative checks.
  • Fixed active-variable capacity must be documented clearly.
  • Fixed-capacity AD can fail when the number of active variables exceeds the compiled limit.
  • Use for small constitutive derivatives and validation, not as a global symbolic assembler.
  • Keep ordinary FE kinematics in kinematics.h .

The global weak-form, CSR assembly, and Newton solver remain the production path unless a weak form explicitly opts into this local helper.
