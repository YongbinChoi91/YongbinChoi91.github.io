Framework / Global system construction

Global Assembly

Local element residuals and tangents are scattered into a global residual vector and CSR tangent matrix.

Purpose

What this module does

Assembly connects physics to the nonlinear solver. It precomputes element DOF maps and CSR indices so Newton iterations update values without rebuilding connectivity.

Local-to-global map

Residual assembly

R = Σe AeT Re

The Boolean map Ae places each element residual entry at its global degree of freedom.

Sparse tangent

CSR value assembly

K = Σe AeT Ke Ae

Connectivity determines the sparsity graph once; Newton iterations update only the CSR values. Independent element work can be parallelized with OpenMP and distributed with MPI.

Algorithm

Precompute DOF maps and CSR indices → evaluate elements → scatter local R and K → reduce parallel contributions → apply constraints

Design point

  • Single-domain and multi-domain problems use the same Problem assembly path.
  • CSR indices are precomputed for fast local-to-global scatter.
  • Generic Neumann/traction assembly is handled outside constitutive kernels.
Extension point

Preserve the local-to-global interface

New domain and element formulations should return local residual and tangent data against a valid element DOF map; the shared CSR scatter path then remains unchanged.
