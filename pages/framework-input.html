Framework / Input layer

Input / Configuration

Text input files are converted into the runtime Problem and ProblemParameters objects used by the solver.

Purpose

What this module does

This module is the user-facing entry point of the code. It reads mesh, DOF, material, boundary-condition, solver, and postprocessing files, then prints a startup summary before calling the unified solver.

Configuration contract

Inputs describe the problem, not the algorithm implementation

Mesh and problem files define geometry and domains; DOF input selects fields; material and boundary inputs define constitutive data and constraints; solver and postprocessing inputs control execution and results.

Boundary conditions

  • DIRICHLETBoundary group, component, and prescribed expression.
  • PRESSURE_DIRICHLETOptional pressure constraint.
DIRICHLET INLET vx u_bar*parabolic_profile
DIRICHLET INLET vy 0.0

Material.txt

Material and model constants

  • rho / muDensity and viscosity.
  • youngs_modulusSolid stiffness parameter.
  • poisson_ratioSolid compressibility parameter.
# Fluid
rho 1e3
mu 1e-3

# Solid
youngs_modulus 5.0e6
poisson_ratio 0.3
Solver.txt

Nonlinear and linear controls

  • solver_backendUMFPACK, PETSc, or optional Pardiso.
  • linear_solverDirect or Krylov method.
  • dt / total_timeTime-integration range.
  • max_iter / tolNewton convergence controls.
solver_backend petsc
linear_solver fgmres
preconditioner fieldsplit

dt 0.01
total_time 5.0

max_iter 20
tol 1e-8
Postprocessing.txt

Result and visualization controls

  • output_rootRoot output directory.
  • Create Folder Name / folder_nameCustom output folder; auto uses the model name.
  • model_output_subdirAppend the model-name folder when no custom name is supplied.
  • hdf5_outputStructured result database switch.
  • vtk_outputVisualization output switch.
  • vtk_intervalAccepted-step output cadence.
output_root ./output
Create Folder Name my_run
hdf5_output on

vtk_output on
vtk_interval 1

final_dofs_output on

The shared application setup resolves this example to ./output/my_run/. Custom names are sanitized and take precedence over model_output_subdir. Use Create Folder Name auto to select the model-name folder instead. The parser requires a nonempty value when either folder-name key is present.

Design point

  • Keep user configuration text-based and reproducible.
  • Allow scalar expressions such as sin, min, max, piecewise, and piecewise_cycle.
  • Keep install/build choices separated from runtime solver choices.
Extension point

Add configuration without coupling it to numerics

New model controls should be parsed into validated problem data. Assembly and solver algorithms should consume that data through the existing problem contract.
