Quadratic polygonal VEM example

A runnable 2D displacement example using quadratic projection, internal quadrature, and DOFI stabilization.

Strong form

Finite-strain equilibrium on a polygonal domain.

\[-\operatorname{Div}\mathbf P(\mathbf F)=\mathbf 0\quad\text{in }\Omega_0, \qquad \mathbf F=\mathbf I+\nabla_0\mathbf u.\]
Boundary conditions
\[\mathbf u=\bar{\mathbf u}\text{ on }\Gamma_D, \qquad \mathbf P\mathbf N=\bar{\mathbf t}\text{ on }\Gamma_N.\]

The polygon boundary groups and actual prescribed values are listed in input/BC.txt.

Weak form
\[G_E= \int_E \mathbf P(\mathbf F(\Pi^\nabla\mathbf u)): \nabla_0(\Pi^\nabla\delta\mathbf u)\,dV +S_E((I-\Pi)\mathbf u,(I-\Pi)\delta\mathbf u).\]

The consistency term is integrated at the cached internal quadrature points. The DOFI term controls the projection-null component.

Equation-to-code mapping

The implementation follows the projected weak form directly.

Build and run

Copy the verified model and input snapshot into the FEM slots.

cp FEM/models/weak_form.cpp FEM/models/weak_form.cpp.bak
cp -R FEM/input FEM/input.bak
cp Web/examples/vem-quadratic/weak_form.cpp FEM/models/weak_form.cpp
cp Web/examples/vem-quadratic/input/*.txt FEM/input/
make -C FEM MODEL_SRC=models/weak_form.cpp USE_VEM=1 run
