3D Cook’s membrane — hyperelastic solid example

A displacement-only nonlinear solid benchmark. The page separates the theoretical formulation from the simulation workflow, while keeping the actual implementation excerpts close to the input files.

Theory

From Neo-Hookean energy to AD residual and tangent.

The hyperelastic model is state-based: once the displacement field defines the deformation gradient, the stress follows from the strain-energy density. The element weak form is then written once as a scalar statement and differentiated by AD to obtain residual and tangent.

Strong form

Balance of linear momentum in the reference configuration

\[ -\operatorname{Div}\mathbf{P}(\mathbf{F})=\mathbf{0} \quad\text{in }\Omega_0, \qquad \mathbf{F}=\mathbf{I}+\nabla_0\mathbf{u}. \]
Boundary conditions

Essential and traction boundaries

\[\mathbf{u}=\bar{\mathbf{u}}\ \text{on }\Gamma_D, \qquad \mathbf{P}\mathbf{N}=\bar{\mathbf{t}}\ \text{on }\Gamma_N.\]

The fixed and loaded boundary groups and their actual values are defined by input/BC.txt.

1 · Kinematics

Deformation gradient

\[ \mathbf{F} = \mathbf{I} + \nabla_0 \mathbf{u} \]

The displacement field is interpolated from the element DOFs. At every Gauss point, the reference gradient of the displacement defines the finite-strain deformation gradient.

2 · Material law

Compressible Neo-Hookean model

\[ J = \det \mathbf{F}, \qquad \mathbf{C} = \mathbf{F}^{T}\mathbf{F} \]
\[ W(\mathbf{F}) = \frac{\mu}{2}\left(\operatorname{tr}(\mathbf{C}) - d\right) - \mu \ln J + \frac{\lambda}{2}(\ln J)^2 \]

Young’s modulus and Poisson’s ratio are read from Material.txt and converted to Lamé parameters before evaluating the stress response.

3 · Parameters

Input constants to Lamé constants

\[ \mu = \frac{E}{2(1+\nu)}, \qquad \lambda = \frac{E\nu}{(1+\nu)(1-2\nu)} \]

For this example, the material file uses youngs_modulus 200 and poisson_ratio 0.3 .

4 · Stress

First Piola stress

\[ \mathbf{P} = \frac{\partial W}{\partial \mathbf{F}} \]

Because the weak form is integrated over the reference domain, the implementation uses the first Piola-Kirchhoff stress.

5 · Weak form

Element scalar declaration

\[ G_e(\mathbf{u}, \delta\mathbf{u}) = \int_{\Omega_0^e} \mathbf{P}(\mathbf{F}(\mathbf{u})) : \nabla_0 \delta\mathbf{u}\, dV - \int_{\Gamma_{t,e}} \bar{\mathbf{t}} \cdot \delta\mathbf{u}\, d\Gamma \]

This is the central programming idea: the model declares the local weak-form contribution, while the global assembly and solver remain independent of the material model.

6 · AD residual

Differentiate with respect to virtual displacement

\[ \mathbf{R}_{e,i} = \frac{\partial G_e}{\partial (\delta u_i)} \]

The virtual displacement variables are AD variables, so each element residual entry is read from the derivative of the scalar weak-form expression.

7 · AD tangent

Differentiate residual with respect to current DOFs

\[ \mathbf{K}_{e,ij} = \frac{\partial \mathbf{R}_{e,i}}{\partial u_j} \]

The current displacement DOFs are wrapped by an outer AD type, which gives the Newton tangent from the same implementation used to compute the residual.

Input files, execution flow, and implementation excerpts.

The simulation tab focuses on how the formulation is used in the code. The visible snippets are intentionally short: they show the actual computational pattern without turning the documentation page into a full source listing.

2

Material constants

Material.txt provides youngs_modulus and poisson_ratio , which are converted to Lamé parameters.

3

Gauss point kinematics

The element routine computes F = I + Grad(u) from the current element displacement DOFs.

4

Neo-Hookean stress

The helper evaluates the first Piola stress from the embedded plane-strain 3D deformation gradient.

5

Element residual/tangent

The weak form is accumulated locally and differentiated by AD to produce ElementSystem .

6

CSR assembly

The generic assembly path scatters the dense element residual and tangent into the global CSR system.

3. Plane-strain embedding before stress evaluation 
template <class Scalar>
inline std::vector<std::vector<Scalar>> embed_3d(
    const std::vector<std::vector<Scalar>>& A,
    int dim
) {
    if (dim == 3) return A;

    auto A3 = hpx::eye<Scalar>(3);
    for (int i = 0; i < 2; ++i) {
        for (int j = 0; j < 2; ++j) {
            A3[i][j] = A[i][j];
        }
    }
    return A3;
}
4. Neo-Hookean first Piola helper 
template <class Scalar>
inline std::vector<std::vector<Scalar>> neo_hookean_first_piola_lame(
    const std::vector<std::vector<Scalar>>& F3,
    double lambda,
    double mu
) {
    const Scalar J = hpx::det(F3);
    const auto FinvT = hpx::inv_transpose(F3);
    const Scalar coeff = Scalar(0.5 * lambda) * (J * J - Scalar(1.0));

    std::vector<std::vector<Scalar>> P(3, std::vector<Scalar>(3, Scalar(0.0)));
    for (int i = 0; i < 3; ++i) {
        for (int A = 0; A < 3; ++A) {
            P[i][A] = Scalar(mu) * (F3[i][A] - FinvT[i][A])
                    + coeff * FinvT[i][A];
        }
    }
    return P;
}

6. Local weak-form Gauss point contribution 
for (const auto& gp : gauss_rule(geom.type, params.solver.gauss_order)) {
    const ShapeData shape = compute_shape(geom.type, gp.xi, gp.eta, gp.zeta);
    const JacobianData J = compute_jacobian_data(geom, shape);
    const auto dNdx = compute_dN_dx(shape, J);

    const auto F  = hpx::deformation_gradient<ADScalar>(L, x_elem_ad, dNdx);
    const auto F3 = hpx::embed_plane_strain_3d(F, mesh.dim);
    const auto P  = hpx::neo_hookean_first_piola_lame(F3, lambda, mu);

    for (int a = 0; a < L.n_nodes("displacement"); ++a) {
        for (int i = 0; i < mesh.dim; ++i) {
            const int ia = L.dof("displacement", a, i);
            for (int A = 0; A < mesh.dim; ++A) {
                G += P[i][A] * dNdx[a][A] * delta_u[ia] * J.detJ * gp.weight;
            }
        }
    }
}
7. Generic element-to-CSR assembly 
void assemble_element_system_csr(
    const ElementSystem& es,
    const std::vector<int>& dofs,
    const std::vector<int>& idx,
    Vector& R,
    CSRMatrix& K
) {
    const int n = static_cast<int>(dofs.size());
    for (int a = 0; a < n; ++a) {
        R[dofs[a]] += es.residual[a];
        const int row = a * n;
        for (int b = 0; b < n; ++b) {
            K.values[idx[row + b]] += es.tangent[row + b];
        }
    }
}
