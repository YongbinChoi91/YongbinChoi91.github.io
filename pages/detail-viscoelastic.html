Finite-strain viscoelasticity with local internal metric

This page uses the same documentation platform as the elastoplastic example, but the local state is now a viscous right-Cauchy-Green-type metric. The global solve is still displacement-only; the history variables live only at Gauss points and are updated by a local Newton problem.

Theory

Finite-strain viscoelastic update from a local metric equation.

The unknown solved by the global Newton method is the displacement field. The viscous internal variable is stored locally as a symmetric tensor \(\mathbf{C}_v\). At each Gauss point, the current deformation gradient \(\mathbf{F}\) and the previous accepted history \(\mathbf{C}_{v,n}\) define a nonlinear local residual \(\mathbf{Q}=\mathbf{0}\). Solving this local problem gives the updated history and the algorithmic stress used in the global weak form.

1 · Kinematics

Current deformation and elastic left metric

\[ \mathbf{F}=\mathbf{I}+\nabla_0\mathbf{u}, \qquad \mathbf{C}=\mathbf{F}^{T}\mathbf{F} \]
\[ \mathbf{b}_e=\mathbf{F}\mathbf{C}_v^{-1}\mathbf{F}^{T} \]

The total deformation is measured by \(\mathbf{F}\), while the viscous metric \(\mathbf{C}_v\) separates the elastic part through \(\mathbf{b}_e\). Initially, the history is zero, meaning \(\mathbf{C}_v=\mathbf{I}\).

2 · History variables

Stored Gauss-point metric

\[ \mathbf{C}_v(\mathbf{h})= \begin{bmatrix} 1+h_{11} & h_{12} & 0 \\ h_{12} & 1+h_{22} & 0 \\ 0 & 0 & 1+h_{33} \end{bmatrix} \qquad \text{plane strain} \]
\[ \mathbf{h}_{2D}=\begin{bmatrix} h_{11} \\ h_{22} \\ h_{33} \\ h_{12} \end{bmatrix} = \begin{bmatrix} C_{v,11}-1 \\ C_{v,22}-1 \\ C_{v,33}-1 \\ C_{v,12} \end{bmatrix} \]

The website shows the history in tensor form first, matching the plasticity page style. The code stores the independent entries as a compact Gauss-point vector only for memory layout. At initialization \(\mathbf{h}=\mathbf{0}\), so \(\mathbf{C}_v=\mathbf{I}\).

3 · Stress

Kirchhoff stress from the elastic metric

\[ \boldsymbol{\tau}=2\mathbf{b}_e\frac{\partial \psi(\mathbf{b}_e)}{\partial \mathbf{b}_e} \]
\[ \boldsymbol{\tau}=p\mathbf{I}+\mu J_b^{-1/3} \left(\mathbf{b}_e-\frac{\operatorname{tr}(\mathbf{b}_e)}{3}\mathbf{I}\right), \qquad p=\frac{\kappa}{2}(J_b-1) \]

The model uses a compressible Neo-Hookean-type Kirchhoff stress, but it is evaluated on the elastic metric \(\mathbf{b}_e\), not directly on the total \(\mathbf{F}\mathbf{F}^T\).

4 · Local residual

Viscous flow equation

\[ \dot{\mathbf{C}}_v\approx\frac{\mathbf{C}_v-\mathbf{C}_{v,n}}{\Delta t} \]
\[ \mathbf{d}_v=\operatorname{sym}\left( \frac{1}{2}\mathbf{F}^{-T}\dot{\mathbf{C}}_v\mathbf{C}^{-1}\mathbf{F}^{T} \right) \]
\[ \mathbf{Q}=-\operatorname{dev}\left(\boldsymbol{\tau}-\eta\mathbf{d}_v\right), \qquad \det(\mathbf{C}_v)-1=0 \]

The deviatoric balance drives the viscous evolution, while the determinant constraint keeps the internal metric volume-preserving. The viscosity \(\eta\) controls the relaxation speed and hysteresis width.

5 · Consistent tangent

Implicit differentiation of the local solve

\[ \mathbf{Q}(\mathbf{F},\mathbf{h})=\mathbf{0}, \qquad \frac{d\mathbf{h}}{d\mathbf{F}} =-\mathbf{Q}_{\mathbf{h}}^{-1}\mathbf{Q}_{\mathbf{F}} \]

The local Newton problem is solved in double precision. Then the derivative of the converged history with respect to \(\mathbf{F}\) is injected into the AD variables, so the global tangent includes the hidden dependence \(\mathbf{h}(\mathbf{F})\).

6 · Weak form

Global displacement residual

\[ G_e=\int_{\Omega_e}\mathbf{P}(\mathbf{F},\mathbf{h}(\mathbf{F})): \nabla_0\delta\mathbf{u}\;dV \]

After the local update, the element contributes the same scalar weak-form potential style used by the other solid models. AD extracts the residual and the global Newton tangent from this scalar expression.

Why this belongs in the inelastic section

The response depends on the loading history and the time step. Even if the global unknown vector has only displacement DOFs, each integration point carries memory through \(\mathbf{C}_{v,n}\).

What visitors should notice

Plasticity and viscoelasticity share the same platform: declare history variables, solve a local residual, recover the consistent tangent, assemble through the generic CSR path, and plot the global response through the same postprocessing module.

Simulation

Input files and implementation flow for the cyclic example.

This section explains how the theory is connected to the actual C++ run. The example uses a displacement-only mesh, a four-variable viscoelastic history declaration, cyclic displacement control, local-history diagnostics, and hysteresis postprocessing.

DOFS_info.txt

Declare global and local variables separately. 

field_key displacement
history viscoelastic 4

The first line creates the global displacement DOFs. The second line creates four local history values at every Gauss point; these values are never assembled as global unknowns.

Material.txt

Use elastic constants plus viscosity. 

YOUNGS_MODULUS 200.0
POISSON_RATIO 0.3
VISCO_ELASTIC_ETA 50
LOCAL_RESIDUAL_TOL 1.0e-10
LOCAL_MAX_ITER 25

\(E\) and \(\nu\) define the equilibrium elastic response. \(\eta\) controls the rate-dependent part of the material and therefore the size of the hysteresis loop.

BC.txt

Cyclic displacement loading. 

DIRICHLET LEFT ux 0.0
DIRICHLET BOTTOM uy 0.0
DIRICHLET TOP uy piecewise_cycle(4.0; 0,0; 1.0,0.15; 2.0,0; 3.0,-0.15; 4.0,0)

The horizontal motion is fixed on the left, the bottom vertical motion is fixed, and the top boundary receives a periodic vertical displacement over a four-second cycle.

Postprocessing.txt

Write the hysteresis curve directly. 

hysteresis_output on
hysteresis_x_axis prescribed TOP uy 1.0
hysteresis_y_axis reaction BOTTOM uy 1.0

The x-axis follows the prescribed top displacement and the y-axis stores the bottom reaction force. This gives a clean force-displacement loop for the viscoelastic response.

Local residual Q

The Gauss-point equation is written explicitly.

In the simulation page the hidden algorithm should be visible: the code first builds \(\mathbf{C}_v\), \(\mathbf{C}_{v,n}\), \(\mathbf{C}=\mathbf{F}^T\mathbf{F}\), \(\dot{\mathbf{C}}_v\), \(\mathbf{b}_e\), \(\boldsymbol{\tau}\), and \(\mathbf{d}_v\). Then it solves the residual \(\mathbf{Q}(\mathbf{F},\mathbf{h})=\mathbf{0}\) for the updated history.

\[ \mathbf{Q}_{dev}=-\operatorname{dev}\left(\boldsymbol{\tau}-\eta\mathbf{d}_v\right), \qquad Q_{vol}=\det(\mathbf{C}_v)-1 \]
\[ \mathbf{Q}_{2D}=\{Z_{11},\;Z_{22},\;\det(\mathbf{C}_v)-1,\;Z_{12}\}, \quad \mathbf{Z}=\mathbf{Q}_{dev} \]
Stress recovery

After local convergence, P is evaluated from the updated metric.

Once local Newton converges, the trial history \(\mathbf{h}_{n+1}\) is inserted back into the AD graph using \(d\mathbf{h}/d\mathbf{F}\). The code then reconstructs \(\mathbf{C}_v\), computes \(\mathbf{b}_e\), evaluates \(\boldsymbol{\tau}\), and finally obtains the first Piola stress.

\[ \mathbf{P}=\boldsymbol{\tau}\mathbf{F}^{-T}, \qquad G_e=\int_{\Omega_e}\mathbf{P}:\nabla_0\delta\mathbf{u}\;dV \]
1. The active model is displacement-only. 
const char* active_constitutive_model_name() {
    return "viscoelastic_solid_displacement_history";
}

std::vector<std::string> active_constitutive_field_names(const FieldMesh& mesh) {
    (void)mesh;
    return {"displacement"};
}
2. Material parameters are read into the local viscoelastic model. 
m.E = params.material.youngs_modulus;
m.nu = params.material.poisson_ratio;
m.eta = params.material.visco_elastic_eta;
m.local_tol = params.material.local_tol;
m.local_max_iter = params.material.local_max_iter;
3. At each Gauss point, the previous accepted history is used as the local state. 
if (gh.h_n.size() < required_history) {
    gh.h_n.assign(required_history, 0.0);
    gh.h_trial.assign(required_history, 0.0);
}

const Mat3T<double> F_double =
    hpx::deformation_gradient_array<double>(dim, dN, u_double);
4. The local residual Q is the actual algorithm, not just a black-box update. 
const auto Cv = Cv_from_hT<T>(h, dim);
const auto Cv_n = Cv_from_hT<T>(h_n, dim);
const auto C = hpx::right_cauchy_green3<T>(F);
const auto dCdt = (Cv - Cv_n) / dt;

const auto be  = F * inverse(Cv) * transpose(F);
const auto tau = tau_from_beT<T>(be, mat);
const auto dv  = sym(0.5 * inverse(transpose(F)) * dCdt * inverse(C) * transpose(F));

const auto Z = -dev(tau - eta * dv);
Q_2D = {Z11, Z22, det(Cv) - 1, Z12};

This is the part that makes the viscoelastic section comparable to plasticity: the local unknown is \(\mathbf{h}\), and the Gauss-point Newton solve drives \(\mathbf{Q}\) to zero before the global residual is assembled.

5. Local Newton solves Q_h Δh = -Q with a positivity line search. 
for (int it = 0; it < mat.local_max_iter; ++it) {
    const Vector Q = local_Q_viscoelastic(F, h_n, h, dim, dt, mat);
    const Matrix Q_h = local_Q_h_sacado(F, h_n, h, dim, dt, mat);
    const Vector dh = solve_dense(Q_h, -Q);

    // line search: accept only positive det(Cv) and non-increasing |Q|
    h = h + alpha * dh;

    if (norm(Qnew) < local_tol || norm(dh) < local_tol)
        return h;
}
6. The implicit tangent exposes h(F) to the global AD tangent. 
Q(F, h(F)) = 0
Q_F + Q_h * dh_dF = 0

dh_dF = - inverse(Q_h) * Q_F

const std::vector<Scalar> h_ad = make_algorithmic_h_ad(
    F_ad, F_double, gh.h_n, upd.h, dim, state.dt, mat
);

Without this step, the global tangent would see the updated history as a constant and the Newton matrix would miss the local relaxation sensitivity.

7. P is recovered from the converged local metric and inserted into G. 
const auto Cv_ad = Cv_from_hT<Scalar>(h_ad, dim);
const auto be = F_ad * inverse(Cv_ad) * transpose(F_ad);
const auto tau = tau_from_beT<Scalar>(be, mat);
const auto P_ad = tau * inverse(transpose(F_ad));

G += P_ad[i][A] * grad_test[i][A] * dV;

This is the final bridge from the local viscoelastic algorithm to the global finite-element residual: \(\mathbf{P}\) is not guessed directly; it is computed after solving \(\mathbf{Q}=0\).

8. Local diagnostics can report residual and iteration count. 
history_diagnostics on

For this model, diagnostics are useful for checking whether the internal metric update is converging consistently over the whole mesh and whether the viscosity/time-step choice makes the local solve hard.

Strong form
\[-\operatorname{Div}\mathbf P(\mathbf F,\mathbf C_v)=\mathbf0\quad\text{in }\Omega_0.\]
Boundary conditions
\[\mathbf u=\bar{\mathbf u}(t)\text{ on }\Gamma_D,\qquad \mathbf P\mathbf N=\bar{\mathbf t}\text{ on }\Gamma_N.\]
