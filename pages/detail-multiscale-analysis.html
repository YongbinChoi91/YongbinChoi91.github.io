Multiscale / Computational Homogenization

Computational Homogenization

An equilibrated RVE supplies the macroscopic stress and tangent. Follow that transfer for elastic and history-dependent micro models, then run the 2D examples.

Elastic / Theory

From micro equilibrium to macroscopic stress and tangent.

Elastic here includes the finite-strain hyperelastic model. Its material law is explained in Solid / Hyperelasticity; this page follows the response and its sensitivity through the RVE and back to the macro solve.

1

Macro → Micro

Send the current macroscopic deformation gradient \(\bar{\mathbf F}\) to a periodic RVE problem.

2

Equilibrate and differentiate

Converge the micro displacement and periodic multipliers, then solve for their sensitivity to \(\bar{\mathbf F}\).

3

Micro → Macro

Return averaged Piola stress \(\bar{\mathbf P}\) and tangent \(\bar{\mathbb A}\) for the macro residual and Newton matrix.

1 · Micro material response

Stress and material tangent

\[\mathbf P_\mu=\frac{\partial W_\mu}{\partial\mathbf F_\mu},\qquad\mathbb A_\mu=\frac{\partial\mathbf P_\mu}{\partial\mathbf F_\mu}.\]

The micro kernel uses these local derivatives to assemble equilibrium and the derivative of integrated stress with respect to its displacement DOFs. The homogenized tangent also includes the resulting redistribution of micro deformation.

2 · Periodic micro equilibrium

The macro deformation enters through the constraints

\[\mathbf u_\mu^+-\mathbf u_\mu^-=(\bar{\mathbf F}-\mathbf I)(\mathbf X^+-\mathbf X^-),\qquad\mathbf B\mathbf u_\mu=\mathbf g(\bar{\mathbf F}).\]
\[\mathbf r_\mu(\mathbf q,\bar{\mathbf F})=\begin{bmatrix}\mathbf r_u(\mathbf u_\mu)+\mathbf B^T\boldsymbol\lambda\\\mathbf B\mathbf u_\mu-\mathbf g(\bar{\mathbf F})\end{bmatrix}=\mathbf0,\qquad\mathbf q=\begin{bmatrix}\mathbf u_\mu\\\boldsymbol\lambda\end{bmatrix}.\]

Periodic multipliers enforce the displacement jumps. An anchor removes rigid translation. The reference geometry and constraint matrix remain fixed while differentiating the converged response.

3 · RVE sensitivity

Differentiate the converged micro equilibrium

\[\mathbf r_{\mu,\mathbf q}\frac{\partial\mathbf q}{\partial\bar{\mathbf F}}=-\mathbf r_{\mu,\bar{\mathbf F}},\qquad\begin{bmatrix}\mathbf K_{uu}&\mathbf B^T\\\mathbf B&\mathbf0\end{bmatrix}\begin{bmatrix}\mathbf u_{\mu,\bar{\mathbf F}}\\\boldsymbol\lambda_{,\bar{\mathbf F}}\end{bmatrix}=\begin{bmatrix}\mathbf0\\\mathbf g_{,\bar{\mathbf F}}\end{bmatrix}.\]

In 2D, the code solves four right-hand sides in the order \(\bar F_{11},\bar F_{12},\bar F_{21},\bar F_{22}\). This gives du_dF with shape ndofs × 4.

4 · Homogenized response

Apply the chain rule, then normalize once

\[\mathbf I_P=\int_{\Omega_\mu^0}\mathbf P_\mu\,dV,\qquad V_\mu=\int_{\Omega_\mu^0}dV,\qquad\bar{\mathbf P}=\frac{\mathbf I_P}{V_\mu}.\]
\[\mathbf C^{\mathrm{int}}=\frac{\partial\mathbf I_P}{\partial\mathbf u_\mu}\frac{\partial\mathbf u_\mu}{\partial\bar{\mathbf F}},\qquad\bar{\mathbb A}=\frac{d\bar{\mathbf P}}{d\bar{\mathbf F}}=\frac{\mathbf C^{\mathrm{int}}}{V_\mu}.\]

The micro model returns volume, intP, and dIntPdu. RveSensitivity.C stores the integrated derivative \(\mathbf C^{\mathrm{int}}\); the macro kernel divides it by the reference volume. Here \(\bar{\mathbf F}\) enters the micro stress through the solved total displacement, as imposed by the periodic constraints.

5 · Macro equilibrium

Use stress for the residual and sensitivity for the tangent

\[G_M(\mathbf u_M;\delta\mathbf u_M)=\int_{\Omega_M^0}\bar{\mathbf P}:\nabla_0\delta\mathbf u_M\,dV-\ell_{\mathrm{ext}}(\delta\mathbf u_M)=0,\qquad\bar{\mathbf F}=\mathbf I+\nabla_0\mathbf u_M.\]
\[\mathbf R_M=\mathbf f_{\mathrm{int}}-\mathbf f_{\mathrm{ext}},\qquad\mathbf K_M\Delta\mathbf u_M=-\mathbf R_M,\qquad\delta G_M=\int_{\Omega_M^0}\nabla_0\delta\mathbf u_M:\bar{\mathbb A}:\nabla_0\Delta\mathbf u_M\,dV.\]

The last expression is the internal tangent contribution. The examples use prescribed external tractions, so their load derivative is zero. The FE or VE macro discretization consumes the same RVE response contract.

6 · Connect to macro AD

Preserve the solved stress while exposing its derivative

\[\mathbf P_{\mathrm{AD}}(\bar{\mathbf F})=\bar{\mathbf P}_*+\bar{\mathbb A}_*:(\bar{\mathbf F}-\bar{\mathbf F}_*).\]

At the current macro iterate, \(\bar{\mathbf F}=\bar{\mathbf F}_*\), so the residual uses the solved RVE stress. AD sees \(\bar{\mathbb A}_*\) when building the Newton tangent. Each new macro iterate requests a new equilibrated RVE response.

1. Four periodic sensitivity solves

core/multiscale/rve_solver.cpp:90

static std::vector<std::vector<double>> compute_rve_displacement_sensitivity(
    const CSRMatrix& Aaug,
    const FieldMesh& mesh,
    const RvePbcSystem& pbc,
    const LinearSolverSettings& settings
) {
    const int ndofs = total_dof_count(mesh);
    const int n_aug = Aaug.n_rows;
    std::vector<std::vector<double>> du_dF(ndofs, std::vector<double>(4, 0.0));

    for (int q = 0; q < 4; ++q) {
        const int i = q / 2;
        const int A = q % 2;
        Vector rhs(n_aug, 0.0);
        for (int r = 0; r < static_cast<int>(pbc.constraints.size()); ++r) {
            const auto& c = pbc.constraints[r];
            if (c.macro_dependent && c.component == i) {
                rhs[ndofs + r] = c.dX[A];
            }
        }
        Vector sol = solve_linear_system_backend(Aaug, rhs, settings);
        for (int a = 0; a < ndofs; ++a) du_dF[a][q] = sol[a];
    }
    return du_dF;
}
2. Integrated-stress chain rule

core/multiscale/rve_homogenization.cpp:88

RveSensitivity compute_rve_macro_sensitivity_from_piola_du(
    const FieldMesh& mesh,
    const std::vector<std::vector<double>>& dPdu,
    const std::vector<std::vector<double>>& du_dF
) {
    const int ndofs = total_dof_count(mesh);
    if (static_cast<int>(du_dF.size()) != ndofs) {
        throw std::runtime_error("du_dF row count must equal the number of displacement DOFs.");
    }
    for (const auto& row : du_dF) {
        if (row.size() < 4) throw std::runtime_error("du_dF must have four columns: F11,F12,F21,F22.");
    }
    if (static_cast<int>(dPdu.size()) != 9) {
        throw std::runtime_error("dPdu must be 9 x ndofs.");
    }
    for (const auto& row : dPdu) {
        if (static_cast<int>(row.size()) != ndofs) {
            throw std::runtime_error("dPdu column count must equal the number of displacement DOFs.");
        }
    }

    RveSensitivity sens;
    for (int p = 0; p < 9; ++p) {
        const int i = p / 3;
        const int A = p % 3;
        for (int q = 0; q < 4; ++q) {
            double value = 0.0;
            for (int a = 0; a < ndofs; ++a) value += dPdu[p][a] * du_dF[a][q];
            const int alpha = q / 2;
            const int B = q % 2;
            sens.C[i][A][alpha][B] = value;
        }
    }
    return sens;
}

1 · Local material update

Differentiate the updated state, keeping accepted history fixed

\[\mathbf Q(\mathbf F_\mu,\mathbf h_{n+1};\mathbf h_n,\Delta t)=\mathbf0,\qquad\frac{d\mathbf h_{n+1}}{d\mathbf F_\mu}=-\mathbf Q_{,\mathbf h}^{-1}\mathbf Q_{,\mathbf F}.\]
\[\mathbb A_\mu^{\mathrm{alg}}=\left.\frac{d\mathbf P_\mu}{d\mathbf F_\mu}\right|_{\mathbf h_n,\Delta t}=\mathbf P_{\mu,\mathbf F}+\mathbf P_{\mu,\mathbf h}\frac{d\mathbf h_{n+1}}{d\mathbf F_\mu}.\]

The previous accepted state \(\mathbf h_n\) and the time increment are fixed during a Newton linearization. The updated trial state \(\mathbf h_{n+1}\) changes with deformation; its derivative contributes to the algorithmic tangent. In elastoplasticity this applies to the active plastic update, while the elastic branch uses its elastic response.

2 · RVE and macro response

Use the algorithmic derivative in both micro equilibrium and stress output

\[\bar{\mathbf P}_{n+1}=\frac1{V_\mu}\int_{\Omega_\mu^0}\mathbf P_\mu(\mathbf F_\mu,\mathbf h_{n+1})\,dV,\qquad\bar{\mathbb A}_{n+1}^{\mathrm{alg}}=\left.\frac{d\bar{\mathbf P}_{n+1}}{d\bar{\mathbf F}_{n+1}}\right|_{\mathbf h_n,\Delta t}.\]

As in the Elastic tab, differentiate the converged periodic RVE system, then combine dIntPdu with du_dF and divide by the reference volume. The local history derivative must be included in both Kuu and dIntPdu for this linearization.

3 · History ownership

Trial during Newton; commit after macro acceptance

\[\mathbf h_n\ \xrightarrow[\bar{\mathbf F}^{(k)},\Delta t]{\mathrm{micro\ solve}}\ \mathbf h_{n+1}^{\mathrm{trial},(k)}\quad\xrightarrow{\mathrm{macro\ step\ accepted}}\quad\mathbf h_{n+1}.\]

Every macro Newton evaluation starts from the last accepted material history. Cached micro displacements and multipliers can warm-start the equilibrium solve. After macro acceptance, trial histories are committed; after rejection, the trial cache is discarded.

4. Separate accepted history from trial warm starts

core/multiscale/multiscale_context.cpp:99

RveWarmStartState get_multiscale_rve_warm_start(int elem_id, int gp_index) {
    std::lock_guard<std::mutex> lock(warm_start_mutex());
    const auto key = std::make_pair(elem_id, gp_index);
    RveWarmStartState out;

    const auto accepted = multiscale_context().accepted_rve_cache.find(key);
    if (accepted != multiscale_context().accepted_rve_cache.end()) {
        out = accepted->second;
    }

    const auto trial = multiscale_context().trial_rve_cache.find(key);
    if (trial != multiscale_context().trial_rve_cache.end()) {
        out.displacement = trial->second.displacement;
        out.lambda = trial->second.lambda;
        out.Fmacro = trial->second.Fmacro;
        out.valid = trial->second.valid;
        // Keep the material history anchored to the last accepted macro state.
        // The trial history is promoted only after the macro time step accepts.
    }

    return out;
}
5. Commit or discard at the macro-step boundary

core/multiscale/multiscale_context.cpp:136

void commit_multiscale_rve_history_cache() {
    std::lock_guard<std::mutex> lock(warm_start_mutex());
    for (auto& kv : multiscale_context().trial_rve_cache) {
        multiscale_context().accepted_rve_cache[kv.first] = std::move(kv.second);
    }
    multiscale_context().trial_rve_cache.clear();
}

void discard_multiscale_rve_trial_cache() {
    std::lock_guard<std::mutex> lock(warm_start_mutex());
    multiscale_context().trial_rve_cache.clear();
}
