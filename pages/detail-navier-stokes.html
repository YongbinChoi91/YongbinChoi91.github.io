Fluid Mechanics / Incompressible Flow

Incompressible Navier–Stokes flow example

A mixed velocity-pressure flow benchmark. The page uses the same Theory / Simulation layout as the nonlinear solid pages: first the governing equations, then the actual C++ weak-form implementation and input files.

Theory

Continuity and momentum equations for incompressible flow.

This first fluid page stays intentionally compact. The visitor only needs to see the mixed unknowns, the incompressibility equation, and the momentum balance before reading the simulation code.

Strong form

Transient incompressible momentum balance

\[\rho(\partial_t\mathbf{v}+(\mathbf{v}\cdot\nabla)\mathbf{v}) -\nabla\cdot\boldsymbol{\sigma}=\mathbf{0}, \qquad \nabla\cdot\mathbf{v}=0\quad\text{in }\Omega.\]
Boundary conditions

Velocity and traction boundaries

\[\mathbf{v}=\bar{\mathbf{v}}\ \text{on }\Gamma_v, \qquad \boldsymbol{\sigma}\mathbf{n}=\bar{\mathbf{t}}\ \text{on }\Gamma_t.\]

The 3D inlet, wall, obstacle, and outlet groups and their actual values are defined by input/BC.txt.

1 · Unknowns

Velocity-pressure pair

\[ \mathbf{v}(\mathbf{x},t) \in \mathbb{R}^{d}, \qquad p(\mathbf{x},t) \in \mathbb{R} \]

The input declaration uses field_key velocity pressure . Therefore the same generic element vector contains the vector velocity block and the scalar pressure block.

2 · Continuity

Incompressibility constraint

\[ \nabla \cdot \mathbf{v} = 0 \]

Pressure acts as the constraint field for this equation. In the discrete system this produces the pressure row of the mixed velocity-pressure Newton system.

3 · Momentum

Transient Navier-Stokes balance

\[ \rho \left( \frac{\partial \mathbf{v}}{\partial t} + (\mathbf{v}\cdot\nabla)\mathbf{v} \right) - \nabla\cdot\boldsymbol{\sigma} = \mathbf{0} \]

The code evaluates the time-acceleration term, the convective term, and the stress-divergence term at each Gauss point.

4 · Stress

Newtonian Cauchy stress

\[ \boldsymbol{\sigma} = -p\mathbf{I} + \mu\left(\nabla\mathbf{v}+\nabla\mathbf{v}^{T}\right) \]

The pressure part contributes -p div(delta_v) , while the viscous part contributes the symmetric velocity-gradient term in the weak form.

Weak form and code mapping

The mixed weak form uses the identifiers from the classical fluid kernel.

\[G_e=\int_{\Omega_e}\rho(\partial_t\mathbf v+(\mathbf v\cdot\nabla)\mathbf v)\cdot\delta\mathbf v +2\mu\boldsymbol\varepsilon(\mathbf v):\boldsymbol\varepsilon(\delta\mathbf v) -p\nabla\cdot\delta\mathbf v+(\nabla\cdot\mathbf v)\delta p\,d\Omega.\]

Simulation

Input files, execution flow, and implementation excerpts.

The simulation tab follows the nonlinear solid page style: short workflow cards first, then real C++ code blocks from weak_form.cpp . The fluid weak form is still a scalar G ; AD extracts the residual and tangent from that scalar statement.

1

Input declaration

DOFS_info.txt declares field_key velocity pressure , so both fields enter the local element vector.

2

Material constants

Material.txt provides rho , mu , and u_bar for the flow model and inlet ramp.

3

Gauss point fields

The element routine interpolates v , p , grad_v , delta_v , and delta_p .

4

Weak-form volume terms

The scalar G accumulates acceleration, convection, viscous stress, pressure stress, and continuity.

5

Stabilization

When enabled, SUPG/PSPG-style residual terms are added through the same scalar weak-form path.

6

Element residual/tangent

Nested Sacado AD computes R = dG/d(delta_x) and K = dR/dx for generic assembly.

template <class Scalar>
static Scalar weak_scalar_classical_fluid(
    const FieldMesh& mesh,
    int elem_id,
    const std::vector<Scalar>& x_elem,
    const std::vector<Scalar>& test_elem,
    const ProblemParameters& params,
    const ElementState& state
) {
    const double dt = state.dt;
    const ClassicalLocalLayout L = make_classical_layout(mesh, elem_id);
    const auto& V = L.field("velocity");
    const auto& P = L.field("pressure");

    const BDFCoefficientsDtMultiplied bdf =
        bdf_coefficients_dt_multiplied(dt, state.dt_previous, state.step);

    Scalar G(0.0);
    const ElementGeometry geom = make_velocity_geometry_element(mesh, elem_id);

    const double rho = params.material.rho;
    const double mu  = params.material.mu;
3. Gauss-point interpolation 
for (const auto& gp : gauss_rule(V.element_type, params.solver.gauss_order)) {
    const ShapeData sv = compute_shape(V.element_type, gp.xi, gp.eta, gp.zeta);
    const ShapeData sp = compute_shape(P.element_type, gp.xi, gp.eta, gp.zeta);
    const JacobianData J = compute_jacobian_data(geom, sv);

    const auto dNv = compute_dN_dx(sv, J);
    const auto dNp = compute_dN_dx(sp, J);
    const double dV = J.detJ * gp.weight;

    const auto v = hpx::field_value_as<Scalar>(L, "velocity", x_elem, sv.N);
    const auto v_n = hpx::field_value_as<Scalar>(L, "velocity", state.x_n_elem, sv.N);
    const auto v_nm1 = hpx::field_value_as<Scalar>(L, "velocity", state.x_nm1_elem, sv.N);
    const auto grad_v = hpx::field_grad_as<Scalar>(L, "velocity", x_elem, dNv);

    const auto delta_v = hpx::field_value_as<Scalar>(L, "velocity", test_elem, sv.N);
    const auto grad_delta_v = hpx::field_grad_as<Scalar>(L, "velocity", test_elem, dNv);
    const Scalar delta_p = hpx::scalar_field_value_as<Scalar>(L, "pressure", test_elem, sp.N);
4. Momentum and continuity contributions to G 
std::vector<Scalar> dt_times_accel(L.dim, Scalar(0.0));
std::vector<Scalar> conv(L.dim, Scalar(0.0));
for (int i = 0; i < L.dim; ++i) {
    dt_times_accel[i] =
        Scalar(bdf.b0) * v[i]
      + Scalar(bdf.b1) * v_n[i]
      + Scalar(bdf.b2) * v_nm1[i];

    for (int j = 0; j < L.dim; ++j) {
        conv[i] += v[j] * grad_v[i][j];
    }
}

const Scalar p = hpx::scalar_field_value_as<Scalar>(L, "pressure", x_elem, sp.N);

Scalar div_v(0.0);
Scalar div_delta_v(0.0);
for (int i = 0; i < L.dim; ++i) {
    div_v += grad_v[i][i];
    div_delta_v += grad_delta_v[i][i];
}

for (int i = 0; i < L.dim; ++i) {
    G += Scalar(rho) * dt_times_accel[i] * delta_v[i] * Scalar(dV);
    G += Scalar(dt) * Scalar(rho) * conv[i] * delta_v[i] * Scalar(dV);
}
for (int i = 0; i < L.dim; ++i) {
    for (int j = 0; j < L.dim; ++j) {
        G += Scalar(dt) * Scalar(mu)
           * (grad_v[i][j] + grad_v[j][i])
           * grad_delta_v[i][j]
           * Scalar(dV);
    }
}
G -= Scalar(dt) * p * div_delta_v * Scalar(dV);
G += div_v * delta_p * Scalar(dV);
5. Optional SUPG/PSPG-style stabilization 
if (params.solver.stabilization) {
    Scalar v_norm2(0.0);
    for (int i = 0; i < L.dim; ++i) v_norm2 += v[i] * v[i];

    const double h_T = std::max(std::sqrt(std::abs(2.0 * dV)), 1.0e-12);
    const double inv_h2 = 1.0 / (h_T * h_T);
    const double inv_h4 = inv_h2 * inv_h2;
    const double time_part = (sigma_BDF * sigma_BDF) / (dt * dt);
    const double visc_part = C_k * nu * nu * inv_h4;
    const Scalar denom = Scalar(time_part + visc_part) + v_norm2 * Scalar(inv_h2);
    const Scalar Tau_M = Scalar(1.0) / sqrt(denom);
    const Scalar Tau_C = Scalar(h_T * h_T) / Tau_M;

    for (int i = 0; i < L.dim; ++i) {
        G += Tau_M * strong_res[i] * grad_delta_v_times_v[i] * Scalar(dV);
        G += Tau_M * strong_res[i] * grad_delta_p[i] * Scalar(dV);
    }
    G += penalty * Tau_C * div_v * div_delta_v * Scalar(dV);
}
6. AD residual and tangent extraction 
ElementSystem compute_constitutive_element_system(
    const FieldMesh& mesh,
    int elem_id,
    const Vector& x_elem,
    const ProblemParameters& params,
    const ElementState& state
) {
    const int n = static_cast<int>(x_elem.size());

    std::vector<WeakOuterFad> x_ad(n);
    std::vector<WeakOuterFad> test_ad(n);
    for (int j = 0; j < n; ++j) {
        const WeakInnerFad x_value(x_elem[j]);
        x_ad[j] = WeakOuterFad(n, j, x_value);
    }
    for (int i = 0; i < n; ++i) {
        test_ad[i] = WeakOuterFad(WeakInnerFad(n, i, 0.0));
    }

    const WeakOuterFad G = weak_scalar_classical_fluid(mesh, elem_id, x_ad, test_ad, params, state);

    ElementSystem sys;
    sys.residual.assign(n, 0.0);
    sys.tangent.assign(n * n, 0.0);

    const WeakInnerFad G_value = G.val();
    for (int i = 0; i < n; ++i) {
        sys.residual[i] = weak_inner_dx(G_value, i);
        const int row = i * n;
        for (int j = 0; j < n; ++j) {
            const WeakInnerFad dG_dxj = (j < G.size()) ? G.dx(j) : WeakInnerFad(0.0);
            sys.tangent[row + j] = weak_inner_dx(dG_dxj, i);
        }
    }
    return sys;
}
