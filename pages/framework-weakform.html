Framework / Physics plug-in point

Weak Form / Constitutive Model

The weak-form module is where the local physics is defined; the rest of the solver stays reusable.

Purpose

What this module does

A constitutive model receives element state and material parameters, then returns an ElementSystem containing local residual and tangent. The currently uploaded weak_form.cpp is used as the quadratic polygonal VEM weak-form implementation.

Local formulation

Residual statement

Re(ue; ve) = 0

The weak form balances internal, external, transient, and coupled contributions on one element. Global indexing is deliberately absent from this definition.

Automatic differentiation

Consistent local tangent

Ke = ∂Re / ∂ue

Automatic differentiation propagates derivatives through the same residual evaluation, keeping the Newton tangent consistent with the implemented physics.

Algorithm

Gather element state → evaluate local residual → differentiate residual → return Re and Ke → assembly

Design point

  • Only the local weak form changes between physical models.
  • History variables stay local at Gauss points.
  • Diagnostics hooks allow multiscale/RVE models to report local convergence.
Extension point

Extend local physics, preserve the global solve contract

A new model defines its element residual, active fields, parameters, and local history. Global assembly and nonlinear control remain reusable.
