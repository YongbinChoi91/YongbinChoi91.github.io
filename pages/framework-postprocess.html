Framework / Output and diagnostics

Postprocessing

The postprocessing layer writes visualization files and diagnostic CSV/SVG outputs without polluting solver logic.

Purpose

What this module does

Postprocessing converts the accepted global solution into VTK field output, force histories, minimum deformation Jacobian diagnostics, and simple SVG plots.

Postprocessing

Convert solved states into interpretable fields

Primary DOFs are evaluated at elements or quadrature points to recover stress, strain, flux, pressure, and other derived quantities. Projection or averaging may map local values to visualization fields.

Design point

  • Boundary-owner recovery is robust for shared FSI meshes.
  • Closed-boundary normal checks catch invalid drag/lift surfaces.
  • Output directories are kept separated: vtk, csv, figures, dofs.
Extension point

Add derived quantities independently of the solve

New output fields should read accepted solution and history state without changing residual assembly or nonlinear convergence behavior.
