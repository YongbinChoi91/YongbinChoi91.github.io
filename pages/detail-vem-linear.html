VEM / Linear polygonal element

Linear virtual element shape functions on polygonal meshes

This page follows the same Theory / Simulation platform as the hyperelastic example, but the focus is different: the key question is not the material model itself, but how a usable displacement interpolation is constructed on an arbitrary polygon when the interior shape functions are virtual.

Geometry preview

Polygonal VEM uses boundary DOFs and a computable projection.

The actual interior basis functions are not explicitly constructed. Instead, the code computes a constant projected gradient from polygon edges and uses a centroid-based fan triangulation whenever an internal integration/stabilization path is needed.

Theory

How the linear virtual shape function is represented without writing it explicitly.

In a polygonal VEM element, the shape functions are defined by their boundary values and polynomial consistency. The framework therefore stores vertex DOFs, reconstructs the polynomial part, and avoids requiring closed-form interior basis functions.

1 · Local space

Virtual scalar space on one polygon

\[ V_h(E)=\{v_h\in H^1(E):\; \Delta v_h=0\ \text{in}\ E,\quad v_h|_e\in\mathbb{P}_1(e)\ \forall e\subset\partial E\} \]

The boundary trace is linear on every edge, but the interior function is not written in closed form. For displacement mechanics, the vector space is simply \([V_h(E)]^2\).

2 · DOFs

Vertex values define the interpolation

\[ \mathbf{d}_E=\{u_x(\mathbf{x}_a),u_y(\mathbf{x}_a)\}_{a=1}^{n_E} \]

Linear VEM does not need midside or internal DOFs. For an \(n_E\)-sided polygon, the displacement block has \(2n_E\) local unknowns in 2D.

3 · Projected gradient

The computable part comes from a boundary integral

\[ \nabla \Pi^\nabla \mathbf{u}_h = \frac{1}{|E|}\int_{\partial E}\mathbf{u}_h\otimes\mathbf{n}\,ds \approx \frac{1}{|E|}\sum_{e=(a,b)} |e|\,\frac{\mathbf{u}_a+\mathbf{u}_b}{2}\otimes\mathbf{n}_e \]

Because the trace is linear on each edge, the edge-average value is enough. This is the main reason linear polygonal VEM can assemble a mechanical weak form without ever evaluating the unknown virtual basis function inside the polygon.

4 · Deformation

Use the projection as the polynomial strain mode

\[ \mathbf{F}_\Pi=\mathbf{I}+\nabla\Pi^\nabla\mathbf{u}_h \]

The hyperelastic stress can be evaluated from the projected deformation gradient. This gives the polynomial-consistent part of the nonlinear weak form.

5 · Fan triangles

Centroid triangulation supplies an internal integration path

\[ E=\bigcup_{e=(a,b)} T_e,\qquad T_e=\operatorname{conv}\{\mathbf{x}_c,\mathbf{x}_a,\mathbf{x}_b\} \]

The current implementation keeps a simple centroid fan. It is useful for internal quadrature, comparison against a T3-like gradient, and stabilization-style blending.

6 · Implemented scalar weak form

Projection plus triangle contribution

\[ G_E = \alpha\sum_{T\subset E}|T|\,\mathbf{P}(\mathbf{F}_T):\nabla\delta\mathbf{u}_T +(1-\alpha)|E|\,\mathbf{P}(\mathbf{F}_\Pi):\nabla\Pi^\nabla\delta\mathbf{u}_h \]

This page presents the implemented linear polygon kernel: the projected gradient carries the VEM consistency, while the fan triangles give a concrete internal contribution. The global residual and tangent are still obtained by differentiating this scalar statement with AD.

Simulation

The code mirrors the theory: cache polygon geometry, compute projected gradients, then differentiate G.

The simulation tab shows the relevant implementation pieces. The global solver remains unchanged: only the element-level weak form and VEM geometry cache are specialized.

    (void)mesh;
    return {"displacement"};

2. Each polygon element is converted into a reusable linear VEM cache. 
const int q_order = (params.solver.gauss_order > 0)
    ? params.solver.gauss_order
    : 1;

const vem::LinearElementCache& cache =
    vem::cached_linear_element(mesh, elem_id, q_order);

The cache contains polygon area, centroid, real vertex slots, scaled edge normals, and the centroid fan triangles used by the internal integration path.

3. The projected VEM gradient is built from edge averages and scaled normals. 
for (int ar = 0; ar < cache.n_real; ++ar) {
    const int br = (ar + 1) % cache.n_real;
    const int a_slot = cache.real_slots[ar];
    const int b_slot = cache.real_slots[br];

    const Scalar u_mid = Scalar(0.5) * (ua + ub);
    grad[i][A] += u_mid * Scalar(cache.edge_normal_scaled[ar][A] / cache.area);
}

This is the code version of \( |E|^{-1}\sum_e |e|\bar{u}_e\otimes n_e \). It is the central bridge between virtual shape functions and an actual computable element matrix.

4. The centroid fan provides triangle gradients for the internal contribution. 
Scalar triangle_part(0.0);
double fan_measure_sum = 0.0;

for (const auto& tri : cache.triangles) {
    fan_measure_sum += tri.measure;
    const auto grad_u_T  = vem::linear_triangle_gradient(cache, tri, x_elem);
    const auto grad_du_T = vem::linear_triangle_gradient(cache, tri, test_elem);

    triangle_part += Scalar(tri.measure)
        * neo_hookean_plane_strain_density(grad_u_T, grad_du_T, params);
}
5. The final scalar G blends projected VEM consistency with the triangle part. 
const double alpha = 0.1;
const auto grad_u_pi  = vem::linear_projected_gradient(cache, x_elem);
const auto grad_du_pi = vem::linear_projected_gradient(cache, test_elem);

const Scalar projected_density =
    neo_hookean_plane_strain_density(grad_u_pi, grad_du_pi, params);

return Scalar(alpha) * triangle_part
     + Scalar(1.0 - alpha) * Scalar(fan_measure_sum) * projected_density;
6. AD extracts residual and tangent from the same scalar statement. 
const WeakOuterFad G = weak_scalar_vem(
    mesh, elem_id, x_ad, test_ad, params, state
);

for (int i = 0; i < n; ++i) {
    sys.residual[i] = weak_inner_dx(G.val(), i);
}

for (int j = 0; j < n; ++j) {
    const WeakInnerFad dG_dxj = G.dx(j);
    for (int i = 0; i < n; ++i)
        sys.tangent[i * n + j] = weak_inner_dx(dG_dxj, i);
}
Strong form
\[-\operatorname{Div}\mathbf P(\mathbf F)=\mathbf0\quad\text{in }\Omega_0.\]
Boundary conditions
\[\mathbf u=\bar{\mathbf u}\text{ on }\Gamma_D,\qquad \mathbf P\mathbf N=\bar{\mathbf t}\text{ on }\Gamma_N.\]

The polygon boundary groups are defined in input/BC.txt.

Weak form
\[G_E=\alpha G_E^{fan}+(1-\alpha)|E|\,G_E^{projection}.\]
