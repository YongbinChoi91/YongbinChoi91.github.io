Framework / Polygonal extension

VEM Extension

The VEM module handles polygonal geometry and projection data while the rest of the solver remains FEM-like.

Purpose

What this module does

VEM-specific geometry, projection, internal quadrature, and moment data are isolated in vem.h/.cpp. The uploaded weak_form.cpp uses these caches to evaluate the current quadratic polygonal VEM model.

Consistency projection

Projected displacement

The virtual displacement is not explicitly available in the element interior. Its polynomial projection is written as

uπ = Nπa

The gradient Galerkin condition gives

Gπ â = bπ,I − bπ,II

The constant coefficients are then fixed by matching the element-wise mean displacement.

Linear VEM

Boundary contribution only

â = Gπ−1bπ,I

For the linear polynomial basis, the divergence contribution vanishes: bπ,II = 0. Vertex-average consistency determines the constant part.

Quadratic VEM

Boundary and internal-moment contributions

â = Gπ−1(bπ,I − bπ,II)

The quadratic projection retains the internal divergence term. The internal moment is reconstructed from nodal data, and the mean-value condition completes the constant coefficients.

Reference: Ph.D. thesis, Section 2.4, especially Eqs. (2.136)–(2.176).

Design point

  • Polygonal element details are hidden from the global solver.
  • Linear and quadratic VEM share the same framework-level assembly path.
  • Projection gradients and DOFI stabilization can be documented independently.
