Kinematics

Header-only tensor utilities are shared by ordinary double evaluation and Sacado automatic differentiation.

Purpose

Shared kinematic layer for weak forms

Kinematics collects the reusable finite-element operations needed inside local weak forms. It provides fast local DOF access, field interpolation support, deformation-gradient construction, and small tensor utilities such as determinant, inverse, transpose, trace, symmetric part, and fixed-size 3×3 tensor algebra.

The functions are header-only and templated, so weak-form files can call the same routines with both ordinary double values and automatic-differentiation scalar types. This keeps the kinematic definitions consistent across solid mechanics, fluid/FSI extensions, history-dependent models, and VEM projections.

Design point

Kinematics is not tied to one constitutive law. It is a shared layer used by weak_form_*.cpp implementations to build gradients, deformation measures, and tensor expressions before residual and tangent evaluation. Since the functions are templated, the same implementation works for both numerical evaluation and Sacado-based automatic differentiation.

  • Weak forms can reuse one consistent definition of local DOF access and tensor operations.
  • Finite-strain 2D cases can still use 3×3 plane-strain tensors.
  • VEM projections can call the same local field and tensor helpers as standard FEM kernels.
