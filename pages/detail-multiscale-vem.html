Elastic / Macro k=1 / Micro k=2

VE² · Linear Macro / Quadratic Micro

A 2D linear macro VEM model coupled to the actual quadratic VEM micro kernel. Separate macro and micro DOF files select orders one and two.

Results

Macro displacement and local RVE response

Response transfer

One equilibrated RVE response per macro evaluation point.

See Computational Homogenization for the sensitivity derivation and Solid for the micro material theory.

Stress and tangent
\[\bar{\mathbf P}=\frac{\mathrm{intP}}{V_\mu},\qquad\bar{\mathbb A}=\frac{\mathrm{C}}{V_\mu},\qquad\mathrm{C}=\frac{\partial\mathrm{intP}}{\partial\mathbf u_\mu}\frac{\partial\mathbf u_\mu}{\partial\bar{\mathbf F}}.\]

The micro model provides volume, intP, and dIntPdu. The periodic solver computes du_dF, and the macro kernel uses the normalized sensitivity in its AD stress expression.

Input

Macro k=1 / Micro k=2

Two load increments: dt 0.1, total_time 0.2; UMFPACK; RVE substepping off. The macro boundary file fixes the left edge and applies NEUMANN RIGHT uy 1.0*t.

Build and run

Run from a HiPaCs checkout.

Activate the environment described in Installation, then run this command from the repository root. The script selects the two model sources and passes input paths directly; results are written under Multiscale/output/web/multiscale-vem/. Interactive plotting is disabled for this command.

bash Web/examples/multiscale-vem/run.sh
Complete build and input command
#!/usr/bin/env bash
set -euo pipefail
case_dir="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
repo_dir="$(cd "$case_dir/../../.." && pwd)"
# Select the canonical models matching the downloadable source snapshots.
make -C "$repo_dir/Multiscale" \
  MACRO_MODEL_SRC=models/weak_form_macro_vem.cpp \
  MICRO_MODEL_SRC=../FEM/models/VEM/weak_form_vem_quadratic.cpp \
  TARGET=bin/web_multiscale-vem
run_dir="$repo_dir/Multiscale/output/web/multiscale-vem"
mkdir -p "$run_dir"
post_file="$run_dir/Postprocessing.txt"
cat "$case_dir/input/solver/Postprocessing.txt" > "$post_file"
printf '\nplot_window off\nplot_each_step off\nmultiscale_plot_show off\n' >> "$post_file"
cd "$run_dir"
export OMP_NUM_THREADS="${OMP_NUM_THREADS:-2}"
exec "$repo_dir/Multiscale/bin/web_multiscale-vem" \
  --macro-mesh "$case_dir/input/macro/Macro_Mesh.txt" \
  --micro-mesh "$case_dir/input/rve/Micro_Mesh.txt" \
  --dofs "$case_dir/input/macro/DOFS_info.txt" \
  --micro-dofs "$case_dir/input/rve/DOFS_info.txt" \
  --macro-bc "$case_dir/input/macro/BC.txt" \
  --material "$case_dir/input/solver/Material.txt" \
  --solver "$case_dir/input/solver/Solver.txt" \
  --post "$post_file"
