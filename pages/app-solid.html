Application / Solid Mechanics

Solid Mechanics

Solid mechanics is organized through the same tabbed platform used by the detailed Theory / Simulation pages. Select FEM for standard element formulations, or VEM for polygonal virtual-element formulations.

Finite Element Method

Standard element branch for elastic, inelastic, and dynamic solids.

The FEM branch uses classical finite-element interpolation, Gauss-point constitutive evaluation, AD-based residual/tangent extraction, and the same global assembly and Newton solver used across the framework.

Elastic

Elastic Solids

Hyperelastic and other elastic material models for large-deformation solid mechanics.

Open elastic models → Inelastic

Inelastic Solids

History-dependent material response including elastoplasticity and viscoelasticity.

Open inelastic models → Dynamic

Solid Dynamics

Transient solid mechanics with inertial residuals, Newmark integration, and local velocity/acceleration histories.

Open dynamic models →

Virtual Element Method

Polygonal element branch focused on virtual shape functions and projection.

The VEM branch keeps the same displacement-based solver platform, but replaces classical element shape functions with polygonal projection, stabilization, and order-dependent virtual-element caches.

Linear VEM
