Framework workflow

One reusable solve path.

Different applications share the same high-level execution sequence: read input, build fields and DOFs, evaluate local weak forms, assemble the global system, solve nonlinear equations, and write outputs.

Mesh / fields

Output
Setup

Input defines the problem

Text files describe fields, domains, materials, boundary conditions, solver settings, postprocessing options, and optional history-variable declarations.

Element loop

Local systems are evaluated repeatedly

At every Newton iteration, each active element computes a residual and tangent from the current trial state and previous accepted states.

Solve

Global nonlinear update

The assembled CSR system is reduced by boundary conditions, solved by the selected backend, and used to update the global DOF vector.
